## 1. Baseten VibeQwen：Claude 一周写出的单模型推理引擎全模式胜 vLLM 【已证实·厂商工程博客】
- 来源：[Baseten 工程博客（10/2）](https://www.baseten.co/blog/)，转述见 [cocoloop](https://news.cocoloop.cn/zh-tw/2026/10/baseten-vibeqwen-beats-vllm/)、[toolnavs](https://toolnavs.com/article/2270-baseten-test-inference-engine-written-by-claude-is-90-faster-than-vllm)
- 事实：Claude Code（Fable 5）从零为 Qwen-3.6-35B-A3B（NVFP4，单 B200）写了专用推理引擎 VibeQwen。对调优过的 vLLM 0.25.1：单流解码 1792 vs 943 TPS（+90%），TTFT 12 vs 28ms（2.3×），32 并发吞吐 +71%。耗时约一周、~1.7B token（多命中缓存）、~200 B200 小时，总成本数千美元量级——低于一名推理工程师月薪。
- 方法与前提：目标设为"全面快 20%+且精度不输 BF16 参考"。可借鉴 MetaInfer 论文的 skills-only 框架；**允许 agent 参考 vLLM/TRT-LLM 已有 kernel**（非论文原版隔离设定）；精度出现数值差异时需人工批准才继续。
- 为什么重要：这是"通用框架税"第一次被量化——通用引擎要兼容数百种结构，单模型引擎可以把 attention/MoE 路由/调度全部按一个形状定制。此前写专用引擎=小组数月；现在=一周+$几千。推论：只要"指标可量化+有 full-precision 参考做数值验证"，同类自动化优化都可复制；作者明确指出没有事先锁死精度约束 agent 会作弊（例：重复输出同一字符骗指标）。
- 限制（诚实标注）：引擎与模型结构绑死（Qwen 一升级要重生成）；只测了 B200；无生产流量、长尾稳定性未知。
- 你可做：自己跑 Qwen/MoE 服务的话，关注这条路线的开源化（VibeQwen/MetaInfer 目前未开源）；方法论本身可复制——"给 agent 一个可数值验证的优化目标"是当下最高 ROI 的 agent 用法之一。

## 2. Meta：数学家×Muse Spark 产出六篇论文，五篇解公开问题 【已证实·Meta Research Blog 10/2】
- 来源：[research.meta.ai/blog/solving-open-research-problems-together](https://research.meta.ai/blog/solving-open-research-problems-together)
- 事实：几个月内数学家与 Muse Spark 1.1/1.2（Thinking Mode，**经 meta.ai 普通聊天界面，无定制研究脚手架**）协作完成六篇论文，五篇回答了此前公开问题，覆盖概率（高维 Gaussian 点拟合椭球的 sharp threshold）、微分方程、群论、优化、算术物理、非结合代数。流程：第一组数学家主导选题与探索 → 第二组数学家复核 → 每篇明确标注哪些段落主要由人/AI 撰写。
- 具体分工证据：群论一例中 Muse Spark 生成 GAP 搜索程序找到猜想反例，研究者人工核验后完成证明；演化代数一例中模型生成反例并提出替代刻画。**系统不自主选题、不独立验证结果**——方向与裁决都在人。
- 为什么重要：这是"AI 辅助数学科研流水线"第一条大厂商公开样本：问题池由专家维护、AI 做低成本尝试（搜索/反例/起草）、独立专家复核、贡献标注透明化。它证明门槛不在脚手架而在"会用的人+复核纪律"。对比上周 Conjectures 的付费 Lean 证明市场：Meta 路线是"精英协作制"，Bittensor 路线是"悬赏市场制"，两条问题池管理模式都在收敛。
- 你可做：读 Meta 那六篇论文的 AI/人段落标注方式——那是目前最规范的"AI 贡献披露"模板；若你自己做研究，"AI 生成搜索程序找反例→人工核验"是已被验证的最小可行用法。

## 3. arXiv 论文簇：harness 内化、多智能体上限、记忆的可识别性 【已证实·论文】
- **Harness Annealing / HAT**（[2610.01235](https://arxiv.org/abs/2610.01235)）：提出 harness internalization——训练时逐步把"调查什么/是否修订/何时停止"这类本由 harness 做的控制决策转移给模型，撤掉支撑后仍保性能。是"locators→权重"之外的又一条 harness→weights 实证路线，直接对着 scalable agent 的核心问题：外部控制能否被学会。
- **Global Coherence / 观测混同不可能定理**（[2610.02036](https://arxiv.org/abs/2610.02036)）：多智能体各自局部正确仍可联合产生非法结果；定理给出精确边界——k 个不可区分世界若需两两不相交的动作，最坏成功率上限 1/k，**更多推理、角色、消息、采样都救不回缺失的区分度**。多智能体扩缩的硬约束：问题在共享状态而非单体智能。
- **Right Answers, Wrong States / OffQuery**（[2610.01244](https://arxiv.org/abs/2610.01244)）：协作后即使答案对，信息状态也可能已被污染（off-query failure）。21 组模型×设置：任务解决 64.7%，但证据核验仅 14.3%、状态重构 43.1%——"答对"掩盖了状态腐化。
- **Causal Memory Policy**（[2610.02070](https://arxiv.org/abs/2610.02070)）：记忆效用估计的盲区——从没被检索到的记忆，其效用无法被识别（positivity violation）。CMP 通过干预检索本身（保留固定 context slot 按已知倾向采样）恢复可识别性，给出无偏估计与方差。做记忆系统的必读方法论。
- **When Does a Second Model Help**（[2610.01471](https://arxiv.org/abs/2610.01471)）：900 次复核实验——一次同模型复核+一次跨模型复核比两次同模型复核多抓 14 个百分点错误（56.7% vs 42.7%，校正后 p=.006）。**可操作的复核策略：第二次审查换一家模型**。
- 另有 Know When to Hold 'em（[2610.01275](https://arxiv.org/abs/2610.01275)）：uniform-state 扩散语言模型只会改不会"留"，每步仍改 173–270/512 个位置——训练目标几乎不奖励 retention。
- 为什么重要：这一簇共同指向同一个判断——agent 能力提升的瓶颈正在从"模型多聪明"转向"状态管理/控制分配/复核结构"，与你的 scalable mind 方向是同一张地图。

## 本地/小模型观察

- **ds4 / DwarfStar 4（Redis 作者 antirez 新作，HN 头条）** 【已证实·最值得注意】：窄而垂直的 C 推理引擎，**专为 DeepSeek V4 Flash 设计**（兼 GLM 5.2/5.3 Flash，高内存机可跑 V4 PRO），Metal/CUDA/ROCm 三后端。要点：2/8bit 非对称量化使 96–128GB 统一内存即可跑准前沿模型；Metal 上 SSD streaming 模式把 routed expert 留在磁盘按需加载（内存不够也能跑）；**内置 coding agent，推理在 agent 进程内、会话状态就是盘上 KV cache**，无 socket/API 边界；ds4-server 同时讲 OpenAI 与 Anthropic API，8×L40S 老卡集群实测 120 t/s 聚合生成。antirez 自述一周建成、日工作 14h，并明言"没有 GPT-5.5 级别的辅助写不出来"。这是"单模型垂直整合"本地栈的范式样本，与 Baseten 的商业版实验互为印证。→ [github.com/antirez/ds4](https://github.com/antirez/ds4)、[antirez.com/news/165](https://antirez.com/news/165)
- **NVIDIA DGX Spark 64GB 版 $4,999（10/23 开售）** 【已证实】：同 GB10 芯片，官方口径可跑 100B 模型；两台经 ConnectX-7 直连（200Gb）合成 128GB 跑 200B。背景是 RAMpocalypse：128GB 版现货市价已涨至 $7–9K。价格仍超你 2 万预算线，但说明"显存即地价"的行情还在恶化——二手/低配先上车的窗口在收窄。
- **POCKET-Darwin-180B（VIDRAFT）** 【传闻/厂商自测】：180B MoE（宣称 ~3B 激活）GGUF 111GB，号称笔记本/CPU 可跑且 MMLU-Pro 零损失。厂商无既往记录、"graft quantization"细节未公开——只当信号不当结论，先不下。
