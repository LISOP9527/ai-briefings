## 2. 1000 个 Fable 5.2 agent 复现 FLT 形式化：从专用平台到通用工具，28.7 小时 vs 首次的 11 天——多智能体组织的可读解剖

来源：[claude.dev 工程博文（亲核全文）](https://claude.dev/blog/safely-scaling-multi-agent-teams-with-fable-5-2/)。
**已证实：实验设计、数据库 schema、任务树数据、时间线全部公开于博文；54/60 命题 kernel 过检。需正确读：这是「复现」9 月已有的 FLT 形式化（给定了 60 条命题清单+经典路线一句话梗概+定义+47 条已证引理），不是从零攻下 FLT。**

- **对比口径**：9 月版=研究版模型+Prove2Me 专用平台+研究者引导，11 天、~6B output token、1300 万行 Lean；本次=早期 Fable 5.2×1000 agent（1 lead+999 helper），只有 shell/文件编辑/Lean+Mathlib/个人 Git 分支+共享 Postgres，**无人引导**——28.7 小时（18h 断点续跑+12h）、1/3 output token、证明长度 1/7。**对照组**：同装置 Opus 5.5 在 18h 只完成 26% 且 30h 后几乎不再进展——同 harness 下模型代差直接显形。
- **自组织细节（最值得读的部分）**：lead 前 10 分钟自建五张表（announce/assign/notes/subtasks/landed）；每命题 16–17 人 crew 配 captain；helper 先自评难度——47/60 被判「预算内不可行」，lead 只押 10 条，70 分钟全部证完后 lead 写下「there is no reason to idle」把人全部调回难题；最后 Langlands–Tunnell 一条吃掉 ~750 helper，团队自发长成 2,418 节点、10 层深的任务树。captain 当初估「0.7–1M 行代码、<1% 概率完成」，实际 28.4h 证毕。

- **安全栈**：每 agent 独立 VM 无网络、kernel lockdown、禁 sudo、网关打身份标签；阻塞式分类器逐条审工具调用（fail-closed，阻断即全团停）；CoT+action 双轨监控防「推理说服监控」。这是迄今公开最完整的「大 agent 团队防逃逸」工程描述。

**为什么重要 → 怎么做：**(a) 你的问题池流水线直接可抄：Prove2Me 级专用平台不是必需的——「lead 定方向+crew 制+共享 DB 五表+难度自评→lead 反押注」这套通用件就能组织千人协作，且组织本身是模型涌现的而非人写的；难度自评系统性偏悲观意味着**复核层应该包含「再试一次」而非只验证产出**；(b) 可复现性校准：注意输入里已含 47 条已证引理和路线梗概——这演示的是「协作规模化的成本曲线」（11 天+人 → 29h 无人），不是「新数学能力」；引用时写清楚；(c) 和昨天 TCSExam/AutoDNA 连看：本周「agent 团队做科研」出现了三个不同抽象层的实例（专用平台/通用工具/湿实验仪器抽象），收敛方向是「通用原语+自组织」。

## 8. Apple AMP1：通用大模型零样本操控机械臂碾压专用 VLA/WAM 策略——「LLM 直控物理系统」一周内第二个实验室独立给出同向证据

来源：[arXiv 2611.09892](https://arxiv.org/abs/2611.09892)、[项目页](https://apple-aiml-research.github.io/ml-amp/)、[GitHub](https://github.com/apple-aiml-research/ml-amp)。
**已证实：论文、代码、基准数据公开。有依据：均为作者自测；最优模型是 Gemini 4 Argon（Apple 测的外厂模型，非自家）。**

- **方法**：AMP1 harness——通用模型写 Python 调「感知（RGB-D/点云/可纠正场景模型）+运动（末端路点/夹爪）」接口，harness **不提供任何抓取/推动/放置技能**，模型自己发明策略（找隐藏物、借物当工具、自校准相机）。
- **数字**：RoboLab-120 零样本 85.6%（最强 VLA 49.2%、WAM 42.9%）；真实世界 104/108 次零样本成功（12 任务×3 机型），失败率较 VLA/WAM 降 20x/15x；加跨 episode 持久记忆后 RoboDojo 双臂任务失败率再降 4.6x。局限同样诚实：慢（模型推理时机器人干等）、运动执行中不能打断重想。
- **合看**：Fable 5.2 在 RoboDojo Sim 拿 64.9%（Astra 29.8%）——一周内 Anthropic（发布页）与 Apple（arXiv）各自给出「通用前沿模型当控制器>专用策略」的独立证据，方向收敛；Evolving Agent Teams（Berkeley，10/26 论文本周被放大） supervisor 重组 agent 队写出比专家 FlashInfer kernel 快 1.21x 的 CUDA kernel，则是同逻辑在「编排组织」层的证据。

**为什么重要 → 怎么做：**(a) 「VLA 专用策略是不是死路」变成值得认真问的问题——scalable-mind 框架里「通用模型+工具接口」对「领域专用模型」的替代清单可以加上机器人控制；(b) 工程启发：AMP1 的 harness 设计（不给技能、给可纠正的感知+计时运动原语）和你的问题池工具接口设计同构；(c) 记忆收益 4.6x 是「持久记忆对物理 agent」的第一个干净数字。
