## 1. Claude 解出黑洞物理两个开放问题：agent 群 6 周后台跑、跨题借方法、Lean 验证——AI 自主科研目前最有份量的公开案例

来源：[Anthropic 研究文（亲核全文）](https://www.anthropic.com/research/claude-black-hole-physics)、[HN 428 分](https://news.ycombinator.com/item?id=50562754)、预印本 [hexagonmath 2611.00175](https://hexagonmath.org/2611.00175v1) / [2611.00174](https://hexagonmath.org/2611.00174v1)、[theterminal.space 拆解](https://theterminal.space/ai/claude-black-hole-bootstrap-bound-9-1266)。
**已证实（官方发布+Lean 形式化验证+人类物理学家逐条复核；成果属自述、尚无独立同行评审）：两个结果——(i) Hawking-Page 相变：完成 2003 年 hep-th/0310285 列出但 20 余年无人算完的计算，证明 N=4 SYM 在弱耦合（时空「模糊」区）下相变仍是 abrupt 一阶——黑洞形成不只挂在广义相对论上，是量子理论内生性质；(ii) modular bootstrap：Fable 5.2 在文献数值结果里发现人漏掉的模式，证出最轻黑洞质量精确上界 c/9.1266（闭式 12π²/(π²+4arcsinh²1)），且证明该上界是此方法能做到的最优（不能再降）。对照：Hellerman 2009 证 c/6、Hartman-Mazáč-Rastelli 2019 证 ~c/8.503、数值暗示 ~c/9.1。**

- **过程比结果更值得拆**（官方 methods 节亲核）：8 月研究员 Hongbin Chen 让 Claude 列开放问题→22 个候选→每题一个 agent、**互相能读进度帖、相关时可协作**，后台无特殊配置跑 ~6 周。Hawking-Page 解出数周后，一位独立用 Claude 攻同题的物理学家公布同答案（方法不同，互作检验）。Bootstrap 题：负责 agent 在文献综述时发现数值模式，**另一个在做高维球堆积题的 agent 把模式转成方法**——先复现了 OpenAI 模型近期证的球堆积结果，再把同法用到 bootstrap（此前一个 agent 61 次并行尝试失败）；最终两个其他 agent 独立得到同答案，证明一半沿 OpenAI 证明策略。9 月 Lean 形式化验证；论文由 Claude 主笔、物理学家逐条复核。**「每步计算由独立 agent 做两遍+部分对照文献已知结果」是验证设计的一部分。**
- **含量判断**：这是上期哥德尔笔记本（读文献→定理候选→Coq 复核）的升级版——从「协助释读」到「后台自主选问题-解题-交叉验证-写论文」。方法迁移链（球堆积→bootstrap）是 agent 群「知识复用」的实证，比单点成功更指向 scalable：22 题解出 2 题的命中率也说明当前是「广撒网+运气好」而非稳定产线，别外推过头。
- **保留项**：两结果均不描述真实宇宙、无实用价值（官方自述）；发表渠道是 Anthropic 研究文+hexagonmath 预印本，尚待物理学界独立复核——sysnote 转述提到「两个独立写的验证程序曾一致地都错」的细节，说明独立复算不等于正确（该细节出自二手拆解，原文未在已核部分直接看到，按有依据存疑处理）。

**为什么重要 → 怎么做：**(a) 记入你的「AI 科研自主性」时间线：这是继哥德尔笔记本后第二例「agent 群+长时后台+形式化验证」的公开完整案例，且首次出现**跨问题的方法迁移**——可扩展性的关键证据点；(b) 若复刻到数学问题池：它的 harness 结构（一题一 agent+进度帖互通+独立双算+Lean 兜底+物理学家终审）就是你可以直接抄的流水线，比单 agent 树搜索明确高一档；(c) 读原文而非转述——两个结果的技术细节（尤其 bootstrap 的精确闭式）值得对着预印本看，HN 串里有物理学家讨论可作参照。

## 4. Google 上线 Tool Retrieval（预览）：agent 工具库「按需装配」——与 Anthropic「单 agent 胜多子代理」同日共振成共识范式

**为什么重要 → 怎么做：**(a) 你的多工具 agent 若在 Gemini 上跑：Tool Retrieval 值得立刻试——长尾工具 defer 后输入 token 立竿见影，且 `steps` 里能看模型检索决策（debug 工具命名/描述的现成窗口）；(b) 设计准则更新：工具 >50 就别全量灌 schema（两厂数据都指向同一拐点）；用「名+描述」做检索层、schema 做按需层；(c) 对子 agent 架构：Anthropic 的判据（可测上下文膨胀才拆）比「按职能拆」更硬——先建 10 条 golden eval 再逐个折叠验证，注意他们自报「折叠后某流程 2 跑 1 挂」的回归案例，eval 要跑多次。

## 7. AI-for-math/科研自动化三件：MathEye「最小人工干预补完证明」、Nature 刊文背书 formal proof search、Ai2 Theorizer 开源「文献→定律」流水线

- **MathEye**（[arXiv 2611.22103](https://arxiv.org/abs/2611.22103)）：把 LLM 生成的不完美 Lean 证明转成完全验证证明——「angelic proof checking」：失败片段替换为占位符保留整体结构→证明依赖图上做 residual 分析→**MaxSAT 选最小成本义务集**交给数学家（用普通数学语言提问）→答案自动重建完整证明。30 题分析/代数基准解 93.3%、人工交互次数 -55%。**已证实（arXiv）。**——这正是你问题池缺的「专家复核最小化」工位的形式化：不是「人审全部」而是「人只答机器证明不了的极小闭包」。
- **Nature Computational Science 给 AlphaProof Nexus 发 research highlight**（[11/19](https://www.nature.com/articles/s43588-026-01103-9)）：主流期刊以「formal proof search enables reliable AI-driven mathematical discovery」为题背书 Tsoukalas 等的 Lean-verified 搜索路线——形式化路线获得主流科学出版物的编辑级认可，「证明洪流→可靠性瓶颈→Lean 兜底」叙事进入主流。**已证实（期刊出版）。**
- **Ai2 Theorizer 上线 Asta+开源**（[allenai.org](https://allenai.org/blog/theorizer)+[GitHub](https://github.com/allenai/asta-theorizer)）：文献→结构化理论的流水线：查询→检索 ≤100 篇→按 schema 抽取证据→生成 ⟨LAW, SCOPE, EVIDENCE⟩ 三元组理论（4-8 个/查询）→novelty 评分标注「已被确立/可推导/疑似新」。ACL 2026 论文实测：13.7k 篇源论文→2.9k 理论，**literature-grounded 生成在预测后续 4.6k 篇论文结果上显著强于参数记忆生成**。已开源（pip 包+skill），Asta 平台补贴 token。**已证实（官方+论文）。**

**为什么重要 → 怎么做：**(a) MathEye 的 MaxSAT「最小义务集」直接可借鉴：你的问题池复核工位目标函数就该是「最少专家交互数」，它给了优化形式化而非启发式；(b) Theorizer 值得实测——它是「文献综述→可检验定律」而非又一家 summary 工具，对你「低成本尝试候选方向」的池管理有直接用（开源、有 novelty 评分）；(c) Nature highlight 说明「Lean 兜底」已成期刊认可的主流叙事——你的形式化路线押注方向无变化、证据强度+1。
