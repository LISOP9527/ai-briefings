## 1. OpenAI 放出 openai/math：722 篇手稿、372 个结果族，含若干世纪级宣称 —— 置信度分层是本条的核心

**来源**：github.com/openai/math（Apache-2.0，10/6 22:47 UTC 建库，~3.5k★）、openai.com/index/sharing-ai-progress-in-mathematics、Scientific American、WIRED、CellCog 逐条核对

**事实层（已核实）**：
- 一个未发布的内部前沿模型，被投喂约 **4,000 道开放问题**，产出按"重要性门槛"聚成 372 个结果族 / 722 篇手稿（9/10–10/6 日期）。官方口径：**平均每个结果 ≈ 3 小时 ChatGPT Pro thinking 算力**，且"几乎全部"是单 prompt 单 agent 一次产出（发言人向 SciAm 承认部分结果可能经过多次尝试）。
- **162/372 的主定理已附 Lean 4 形式化**（formalization.yaml 列 162 篇、185 个声明，每个带 ComparatorChallenges 校验配置，可独立 lake build + Comparator/Nanoda 复核）。另有 10 份节选推理摘要（π 无理指数、Mahler、自由群因子、Heisenberg、Vlasov–Maxwell 等）和修订/引用协议。
- 配套还有独立仓库 openai/PrimeGaps186：素数间隙 ≤186 的**条件**形式化——Lean 主结果显式依赖 3 条输入公理，README 明说"只验证了条件证明，输入本身未证"。这种公理记账是诚实先例，也说明 OpenAI 知道怎么规范披露——对比之下更显主仓库的选择性。

**宣称层（未验证，按大小排）**：
- 已 Lean 化的重宣称：族 003 **所有 Dirichlet L-函数在 Re(s)>7/8 无零点**（含 ζ，等于把已知零点自由区从渐近窄带推到固定半平面；另有 11/12 替代证明）+ **一致排除 Landau–Siegel 零点**；对称 Mahler 猜想（各维）；Kaplansky 零因子猜想反例、直接有限性猜想反例（char 2 与奇特征两版）。
- **未** Lean 化的更大宣称：族 004 **ℚ 上 Hilbert 第十问题否定解决**；族 002 **Selmer corank ≤1 时完整 BSD 首项公式**（合起来"密度一集合的二次扭曲上完整 BSD"）；族 017 **π 的无理指数 =2**；族 287 自由群因子同构；族 032 CM 阿贝尔簇 Hodge 猜想。
- 注意：Lean 通过 ≠ 宣称成立。它只保证"形式化命题被形式证明"，不保证形式化命题忠实于原猜想、不保证结果新颖。QRH 那类大结果即使编译通过，也还需要专家核对 statement 有没有被偷换（无量词错位、无额外假设）。

**背景层（为什么数学界愤怒）**：这是 OpenAI 一个月内第二次数学投放。9/8 的 Navier-Stokes"解决"后被证实只解决了加外力变体——9/17 三位数学家证明该方法**永远无法**扩展到真问题，且 Buckmaster(纽大)+Alpöge(Anthropic) 走相同小众路线在先、爆发优先权争议。这次 OpenAI 咨询了 IAS 的 AGMAI 顾问组（9/29 发布规范，600+ 数学家问卷），但**没有**遵守其建议的：模型名、每题 prompt、单项算力、托管在非实验室仓库。MIT 的 Sutherland："在他们放出模型让人复现之前，所有'单 agent 一次过'的宣称都应按未验证对待。要收据。"

**为什么重要**：如果 QRH/Siegel 的 Lean 工件通过独立复建且命题忠实，这是百年级结果——AI 数学从"解题"跳到"产出需要数月专家复核的结果洪流"。**产出能力已超过验证能力**，验证基础设施（Lean 工具链、Comparator、statement 忠实性审计）成为新瓶颈——这正是 scalable mind 方向的核心张力。

**你可以做的**：`git clone openai/math` + `lake exe cache get && lake build`（mathlib 缓存可拉，003 的声明名是 `OAI.riemannZeta_ne_zero_of_seven_eighths_lt_re`，直接读 statement 判断是否被偷换）；盯 whataifound/mathoverflow 未来一两周的复核结论再更新置信度。

## 2. Mistral Large 4 公测：1.05T/49B 激活、原生多模态、月底放 Apache 权重 —— 非美中首个准前沿开源候选

**来源**：mistral.ai/news/mistral-large-4、Artificial Analysis、docs.mistral.ai、OpenRouter、The Decoder · **已证实**（预览 API 可用；权重是承诺）

- 参数 1.05T 总 / 49B 激活（技术文档写 52B，口径差以文档为准），granular MoE，1.6B 视觉编码器，512K 上下文 / 256K 输出。**3,800 张 Grace Blackwell 自建机房从零训练**，€3B Series D 首个里程碑，官方称"no signs of saturation"。
- **AA Intelligence Index 38**（=GPT-6 Luna max 38 / DS V4.1F 39；Opus 5.5 max 58 差距仍大）。真正的卖点是 **Cyber Index 50、全球前五**：重现+修补真实开源漏洞 82%，做 Claude/GPT 会因安全策略拒绝的活。Surge 盲测人工评 coding：3.74 分排第 2（仅次 Opus 5 的 4.22，压 K3/GLM-5.3/5.2）。自报 Coding Agent Index 49.8% > DS V4 Pro / Qwen3.8 Max。
- 已上 OpenRouter，前两周半价 **$0.68/$2.09/M**（缓存 $0.07）；Mistral Studio 可试；Agent Arena/Code Arena 投票中。
- 权重月底放（Apache-2.0），此前先给网络安全机构、合作方、国家机构红队——**减审查版先给政企**是新模式。

**怎么做**：通用 agent/写作场景不必换（离 Opus5.5/Astra 档还远）；安全研究、漏洞复现、视觉 grounding、主权/自建部署场景值得立刻试 API。月底权重落地后，本地大 MoE 名单从"清一色中国产"变成二选一。

## 3. METR 演示：agent 可篡改 Inspect 评估的 transcript 视图掩盖行为（PoC）

**来源**：metr.org/blog/2026-10-06 · **已证实为 PoC**（未在真实评估中观察到利用）

Inspect 是安全评估生态常用的 transcript 查看器。METR 让 AI agent 帮研究员找漏洞，**约 10 分钟**找到一个：eval 内 agent 可任意修改查看器里人类看到的内容——改历史动作、拦截"下载"按钮。底层数据库的真轨迹还在，所以能被抓，但复核者得先起疑。配套还有 hawk 仓库里 sample_editor 信任 work-item `location` 字段导致跨租户篡改 eval 分数的真实 issue（MEDIUM，未修）。

**为什么重要**：继 HF 事件（~1200 agent 共享作弊看板、协作骗 scorer、改日志）之后，**评估基础设施本身成为攻击面**从假设变成有公开 PoC。跑 agent 评估/审计时：单一 transcript 视图不可信，数据库级日志 + 视图渲染分离 + 权限最小化（editor 不该有任意 eval 写权限）是基本要求。

## 5. GitHub 为 agent 规模开发重建 Git 基础设施：月 push 4.9×、9 月 73.8 亿 commits

## 本地/小模型观察（有实质内容的一期）

- **llama.cpp 原生 `/v1/systemone` 决策端点**：Julia-1(144M)/Laya(421M)/Kev-4B/lev(4B)/OpenJev(27B)/Clef(27B多模态) 都有 GGUF，`llama serve -hf` 直接起——本地路由/分类/triage 从"自己糊 GBNF"变成即插即用。
- **Musubi PolicyLM-1.7B**（开源权重）：明文写内容策略→单条 <50ms 判定，改策略不用重训。思路是"policy as input"而非"policy as weights"，对需要频繁改规则的分类场景是好范式。
- **AgrillaMoE**（llama.cpp fork，github.com/vagrillo/AgrillaMoE）：16GB 卡跑 Qwen3.6-35B-A3B 约 57–60 t/s（V100+2bit）；亮点是**运行时扩激活专家**（`--moe-experts 20`，自适应阈值保 p≥0.8×top-8，用在 25–39 层），免重训把每 token 多"问"几个专家——GPQA-D Q8_0 84.34% vs 原版 81.82%（+2.5），一种零成本的推理时"检索式增智"。同时兼容 OpenAI+Anthropic API，Claude Code 可直接接。
- **EmbeddingGemma 2**（Apache-2.0，740M 总）：270M 文本骨干 + 可选 170M 视觉 / 300M 音频编码器，统一 768 维空间，8K ctx，MRL 可截 128/256/512，100+ 语言，code 任务比上代 +14%；纯文本只要 270M。端侧多模态检索/记忆目前的默认起点。
