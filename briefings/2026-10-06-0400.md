## 1. Reflection 发布 Beam：501B 总参/23B 激活稀疏 MoE，Apache 2.0 权重本月放出
- 来源：https://reflection.ai/blog/introducing-beam （HN 302 分）
- **已证实**：发布与训练规模；benchmark 为厂商自报，未经独立验证。
- 细节：23.8T token 预训练；RL 阶段用 10,500×GB300 跑 4 周，>1 亿次 rollout、约 13 亿次沙箱运行、最长 256K 上下文、百万级环境。自报分数：DeepSWE 44.4 / SWE-Pro-v2Hard 77.2 / TB2.1 80.1——约追平 GLM 5.2、逼近 Qwen3.8-Max，但离 Kimi K3 / DeepSeek V4.1F 仍有明显差距。核心卖点是"同等推理分算力省 3–4×"（对比口径不含 prefill/attention/serving 开销，需打折看）。
- 为什么重要：美国厂商久违地往开源权重前沿砸钱。之前西方开源只能捡中国模型的剩饭；若效率主张为真，自托管 agent worker 池的成本账会变。
- 怎么做：现在只能排 waitlist，权重本月内放出再实测。验证重点是"每美元完成的真实任务量"，不是 benchmark。

## 2. Ansatz：跨问题图记忆的数学研究 agent（arXiv 2610.02945，Terence Tao 署名）
- 来源：https://arxiv.org/abs/2610.02945 （UCLA：Wei Wang / Nanyun Peng / Raghu Meka / Amit Sahai + Tao）
- **有依据**（论文+作者阵容强）；成果自报，待社区复核。
- 内容：Continual Graph Memory——把证明搜索全程的事实/计划/反例建成一张可演化图；依赖感知检索供给局部上下文；证据敏感 curator 蒸馏"教训"；scoped recall 把历史陈述和负面结果拿出来局部重证而非无脑复用。结果：关闭全部 10 个 First Proof Second Batch 任务；无人干预产出 Jamison caterpillar conjecture 与 Erdős 289/348/488 的解（289 在 erdosproblems.com 仍标 OPEN、488 标 FALSIFIABLE——若复核通过是真新解）。
- 为什么重要：这正是"AI-for-math 流水线化"缺的那块——跨问题知识复用。此前每道题都是孤立 rollout，Ansatz 把数学研究变成可积累的工程系统。和 Muse Spark、Conjectures 子网、Leder 渗流连起来看：问题池→廉价尝试→记忆复用→专家复核的流水线正在成形。
- 怎么做：盯 erdosproblems.com 状态与社区复核；其机制（scoped recall、负面结果入库）可直接搬进自己的 agent 设计。

## 3. SemiAnalysis 实测：Claude 订阅的 API 等价价值 ≈ OpenAI 同档 5 倍
- 来源：https://newsletter.semianalysis.com/p/anthropic-subscriptions-offer-5x
- **已证实**（买齐各档订阅实测用量表）。
- 细节：OpenAI 上周"核选项"——$200 档 API 等价价值腰斩、新增 $500 Pro 档；Anthropic 反向：Opus 5.5 降价同时 Max 档 Opus 额度 +20%、Pro +50%。毛利测算：$200 档跑满 Opus 5.5 = -369% 毛利（跑满 Fable 5.1 ≈ 1%）；订阅只占 ~10% 收入却吃掉 >40% 推理算力。
- 为什么重要：直接改变订阅决策——同价 $200，Claude 在中端档（Opus 5.5 vs Sol 6.1）能跑的量约 5 倍。同时说明订阅对 lab 是亏本生意，两边都在收紧，窗口期思维。
- 怎么做：按 (plan, model, workload) 重算自己的用量；主打 coding agent 的话当前 Claude $200 档显著占优。

## 5. Together Link：一行命令把现有 coding agent 切到开源模型，内置 Auto 路由
- 来源：https://www.together.ai/blog/together-link-frontier-quality-open-models-in-the-harness-you-already-use
- **已证实**。
- 内容：Claude Code / Codex / OpenCode / Pi Code / Claude Desktop / ChatGPT Desktop 六款一键接入；默认 Auto router 按 session 首个任务分流——简单活去 GLM 5.3（$0.30/$1.20），难活去 Opus 5.5（$3/$15，走你自己的 Anthropic key）；退出时打印本 session 的 token 与美元账单小票。宣称降本 >50%。
- 为什么重要："harness 不动、换模型省钱"最顺滑的实现——路由做在代理网关层而非改你的配置，用完可一键切回。
- 怎么做：可直接试。把小任务打到 GLM 5.3 / Kimi K3，对比 session 小票验证省多少。

## 6. 决策模型继续扩张：Liquid d1 首个支持图像输入的决策模型，$0.04/M 只收输入
- 来源：https://www.liquid.ai/blog/d1-decision-model + openrouter.ai/liquid/d1
- **已证实**。
- 内容：`/v1/systemone` 接口，"state + typed questions → choice/score/yes-no + 概率"；图像按 1.5 token/32×32 patch 计；厂商自测比 GPT-6.1 Sol / Opus 5.5 做同类判定更便宜更快；延迟 0.19s。
- 为什么重要：Jev/clef/laya/d1 的决策模型赛道在固化成"路由-分类-策略检查"专用层——LLM 拆成 System1/System2 分工的继续。
- 怎么做：harness 里的路由/审核节点可试 d1 替代 chat 模型的 JSON mode。
