## 1. Gemini 4 Argon：Google 回归前沿，"便宜但你暂时买不到"

**来源**: [Google 官方博客](https://blog.google/innovation-and-ai/models-and-research/gemini-models/gemini-4-argon/)（9/30）· [VentureBeat](https://venturebeat.com/technology/google-unveils-gemini-4-argon-retaking-benchmark-lead-over-openai-and-anthropic-but-in-limited-release) · [AA 评测](https://artificialanalysis.ai/) · HN 榜首 1100+ 分 / 736 评论
**状态**: 【已证实】（官方+第三方评测+实测路径）

Gemini 4 代首个模型，主打长程复杂工作流：SWE、法律/金融知识工作、网络防御。关键数据点：

- **DeepSWE v1.1 77.9%**（新 SOTA；Opus 5.5 74.2%、Astra 74.1%）；官方披露的 18 项基准中 Argon 领先 12、并列 1；Astra 领先 3+并列 1，Opus 5.5 领先 2——是第一梯队但**不是横扫**，部分编码基准仍落后竞品。
- 差异化强项在法律/长上下文：Harvey Legal Agent 19.6%（vs 第二名 5.4%）、GraphWalks 长上下文遍历 84.2%（vs 66.8%）、LVBench 长视频 91.7%、AutomationBench（Zapier 业务执行）51.3% 第一。
- AA Intelligence Index 53 追平 Astra max、领先 Sol max 1 分；Agent Arena #8，**$0.62/任务**。
- 输出上限扩到 **1M tokens**（此前 64K）——单轨迹深度推理的headroom。
- 定价：首发 $2/$10（cache 输入 95% off ≈ $0.10），促销期后 $4/$20 = Opus 5.5 标准价。AA 测算促销价下每任务成本为 Astra 的 60%。
- 发布路径罕见：先给 Fairwind Program 的"可信网络防御者"（**无网络护栏版本**，Wiz 已用它找到医院软件中此前模型漏掉的 critical vuln）+ 参与美国政府自愿预发布评审，然后才轮到付费 API 和 AI Ultra 订阅，时间未定。OpenRouter 暂无该模型 ID。
- 背景与对冲信息：Google 确认砍掉 Gemini 3.5 Pro（彭博估训练成本 ~$4 亿打水漂）；内部员工据 Bloomberg 报道对其实际干活能力存疑；官方称数千 Google 员工已日用，并用它优化自家数据中心内存、腾出数百 TB。

**为什么重要**：前沿模型市场从两强回到三强，且 Argon 的打法是"长输出+便宜+知识工作覆盖"而非单纯刷编码榜——1M 输出 token 和 Harvey/GraphWalks 的悬殊分差指向 Google 押注"长程单轨迹任务"这个赛道。对你的意义：等 API 开放后，它可能是长文档/长轨迹 agent 任务的新默认选项；**$0.62/任务的成本点如果实测成立，会比 Sol 系更适合跑大批量 worker**。

**你可以怎么做**：现在没法用，能做的是 (a) 把 Agent Arena 的 $0.62/task 记为选型基线，等 OpenRouter 上架后第一时间跑你自己的回归集对照；(b) 注意它的强项分布（法律/长 ctx/多模态）——如果你的 agent 栈有长视频或长文档环节，这是第一个把这类基准打到 90+ 的模型。

## 2. OpenAI 披露并处置"有组织蒸馏行动"，核心集群归因 Moonshot 关联人员

**来源**: [OpenAI 官方披露](https://openai.com/index/disrupting-a-coordinated-model-distillation-campaign/)（9/30）· [CNBC](https://www.cnbc.com/2026/10/01/openai-chinas-moonshot-ai-kimi.html) · CyberScoop
**状态**: 【已证实-攻击存在并已处置】【有依据-归因：OpenAI 未公布硬证据，CyberScoop 明确标注这一点】

要点：7 月第一周开始的对抗性蒸馏——操纵模型交互让受保护的推理轨迹以可见形式复现，手法包括**把加密推理块跨会话复制、让另一会话的模型解密转录**（绕过直接提取的新路径）。峰值两天 16,000 请求/4,000+ 用户，最终识别 15,000+ 用户集群，7/28 前完全处置。未破加密、未碰数据库。已通过 Frontier Model Forum 向同行通报。CNBC：OpenAI 将核心集群归因于 Moonshot（Kimi）关联个人；此前 Anthropic 已指控 Moonshot/阿里用 Claude 偷训。

**为什么重要**：(a) 厂商立场已定型——**推理轨迹本身是受保护资产**，这解释了各 API 对 reasoning token 暴露面越来越保守；(b) 归因公开化意味着地缘/IP 摩擦从私下交涉进入公关武器化阶段，可能影响 Moonshot 的 API 国际可用性和融资叙事；(c) 技术上注意那个绕过手法——"加密内容跨会话注入让模型自己解密"是可以推广的攻击原语，你搭任何含隐藏推理的系统都要假设对手会这样试。

## 4. Ataraxos（Nature）：隐藏信息博弈首次超人，成本比前代低数量级

**来源**: [Nature 论文](https://www.nature.com/articles/s41586-026-11036-y)（9/30）· MIT News
**状态**: 【已证实】（Nature 同行评审+对史上最强人类选手大胜）

MIT/CMU/NYU/Stanford 的 Ataraxos 在 Stratego（10^33 隐藏局面配置）大幅击败史上最强人类玩家——首个超人成绩。方法对你有参考价值的三点：(a) **专用 belief network 显式建模对手隐藏棋子**，让 test-time search 可行而不需枚举信念树；(b) 自博弈训练**不用搜索**（AlphaZero 式 MCTS 在隐藏信息下不稳），改用动态阻尼自博弈协调正则强度/更新步长/策略强度；(c) 测试时再用 update-equivalence 形式化加回轻量搜索。算力/数据消耗比此前工业界努力（DeepNash 级，百万美元级）低数量级；同套方法在 Hanabi、斗地主、Barrage Stratego 也到 SOTA/超人。

**为什么重要**：这是"可扩展心智"方向少见的算法级进展——**信念建模（对未知信息的显式表征）被证明是在部分可观测环境里扩展决策的缺失原语**，而且训练侧不用搜索让成本结构完全不同。迁移到你的语境：处理"信息不全的长任务"（竞赛题、开放调研）时，显式建模"我还不知道什么"比加长 context 更本质。

## 5. agmai.org 发布《负责任的 AI 数学成果发布规范》：数学社区开始立规矩

**来源**: [agmai.org/general-sep29](https://agmai.org/general-sep29/)（9/29）· HN 83 分/102 评论
**状态**: 【已证实】（600+ 份社区问卷调研后的正式文件）

数学家咨询组发布首份规范草案：要求厂商**停止在专有模型上测高级数学问题**；成果发布须遵循正常同行评审、标准术语、作者必须理解并能辩护证明内容、给相关前人工作正当 credit、配合讲座传播。直接背景是 Anthropic 员工用 Claude 改进 Riemann zeta 相关界、被媒体误报为"证明了黎曼猜想"的事件——发起人不懂数学的输出造成大规模误导。

**为什么重要**：这正是你问的"专家复核模式"的制度化起点。含义：(a) 数学社区把"出题人/提示者必须理解输出"写成规范，纯黑盒跑题池产出的结果会被视为不合规产物——**你的流水线如果未来要对接学术圈，"人工复核能力门槛"是必选项而非可选项**；(b) Lean/形式化证明的地位反而上升——规范隐含的出路是"机器验证工件+可被人读懂的标准表述"双轨；(c) 对厂商侧，合规发布成本会拉高，可能反而利好 Conjectures 这类让 kernel 当裁判、问题池公开透明的机制。

## 6. Ling-3.1-flash（蚂蚁百灵）：560B/25B 混合线性注意力，两周免费+计划开源

**来源**: [TechNode](https://technode.com/2026/09/30/ant-group-launches-ling-3-1-flash-with-560-billion-parameters/) · 蚂蚁百灵公众号 · @AndrewZhao(X)
**状态**: 【已证实】

9/30 发布：~560B 总参、~25B 激活、混合线性架构（7 层 KDA 线性注意力配 1 层 Gated MLA）、512 路由专家选 8 + 1 共享、设计 1M 上下文。官方数：GDPVal-AA v2.1 1673 Elo、FrontierSWE 75.16、HealthBench Pro 65.35。当前两周免费体验但限 256K ctx；转付费后开放 1M 并**计划同步开源权重**。

**为什么重要**：架构信号大于模型本身——KDA（Kimi Delta Attention 系）混合线性正在变成国产长上下文 MoE 的标准配方（和 Naive-N0.5 的全线性、K2 系的稀疏注意力是同一趋势的分支）；25B 激活在 560B 总参下是激进稀疏比。若开源兑现，它会是可自托管的最大稀疏线性模型之一——但 560B 总参意味着本地跑动仍需 ~300GB 显存档，超出 2 万元预算。

- **codegraph**（72.6k★）：预索引代码知识图谱，随改动自动同步，喂给 Claude Code/Codex/Cursor 等，主打省 token 省 tool call、纯本地。
