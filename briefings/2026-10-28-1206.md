## 1. Axiom 完成 CFSG 全形式化：43.1M 行 Lean、24 天、agent 集群——「流水线化」第一次在这个尺度上闭环

来源：[Axiom 博客原文](https://axiommath.ai/research/the-enormous-theorem-formalized/)、[CFSG 项目页+依赖图](https://cfsg.axiommath.ai/)、[GitHub AxiomMath/CFSG](https://github.com/AxiomMath/CFSG)、[UGT 新证论文](https://hexagonmath.org/2610.00575?version=1)、[HN 帖](https://news.ycombinator.com/item?id=50261647)。
**已证实：仓库、sorry-free 声明、标准三公理、构建方式公开可核查（`lake build`，官方称 <24h）；有依据：agent 分工与 24 天工期为官方自述；Lean kernel 负责推理正确性，命题↔历史论证的对应已由人审。**

- 规模：43.1M 行 Lean、205 万 declaration、108 里程碑、覆盖 715 篇文献；基于 Mathlib + 社区项目 Qiuzhen-CFSG 的 ~120 万行存量（第三方前期形式化工作）。对比：Gonthier 团队形式化 Feit–Thompson 用了六年（2012，Coq）。
- 流水线本身就是方法：人类数学家先建 proof map（108 里程碑→~380 任务，10/13 进展停滞后再细分为更小定理）；AxiomProver 的 lead agent 分解与审查、其余 agent 查已有结果或写证明，经 GitHub issue 认领；**工程师自建分布式构建缓存+昂贵有限计算外置成可独立校验的证书，把验证提速数个数量级**——因为 agent 产证速度快过 Lean 复核速度。
- 不是橡皮图章：agent 报告的问题经人筛出 34 处与已发表记录的实质偏差。最重要一处——John Walter 1986 年 Unbalanced Group Theorem 证明里的封闭性断言有显式反例（PSL₂(49) 的域对合中心化子为 PGL₂(7)，其单群成分 PSL₂(7) 因 7 是 Mersenne 素数被排除在该族外）；AxiomProver 用 Solomon 1976 年 maximal 2-components 理论产出**新定理 2.3「preservation of simple tops」**完成绕行。另有 Aschbacher–Smith quasithin 卷中一引理被 SL₂(5) 反例推翻（等号需改不等号）。勘误表将向群论界公开，顾问含 Lyons、Solomon——即 CFSG 原作者本人。
- 诚实边界：这形式化的是**已有数学**（第一代证明），不是发现新定理——但与 OpenAI 上期的「生成新结果」互补，且确实产出了一个新群论结果。Axiom 背景：Carina Hong 创立（Stanford 辍学，~20 人），种子 $64M、A 轮 $200M/$1.6B 估值，Putnam 12/12 后转向「Verified AI」。

**为什么重要 → 怎么做：**对你的 scalable mind 问题，这是目前最完整的「机器协调大规模智力劳动」公开样本：分解（人）→认领（agent）→验证（机器）→疑难（人）四层各就其位，而瓶颈恰好出现在**验证吞吐**——这正是「生成-验证不对称」的直接证据。可操作：(a) 想复现，README 给出 `lake build` 与 axiom 自审计命令，<24h 可验证；(b) 研究其 proof-map/里程碑分解文档——它是公开的「问题池管理」工业实例；(c) 注意区分贡献归属：Lean 证的是所写命题的推理，「形式化忠实于第一代证明」由数学家人审——和上期 ETH 条目同一课。

## 2. Anthropic 也反驳了 ETH：内部 Claude 模型独立发现 2^{O(n·loglog n/√log n)} 的 #3-SAT 算法，Lean 双内核 CI 兜底

来源：[anthropics/formal-math/eth](https://github.com/anthropics/formal-math/tree/main/eth)（README/Lean/paper.pdf）、[TechCrunch 报道](https://techcrunch.com/2026/10/27/frontier-ai-labs-say-their-models-refuted-the-exponential-time-hypothesis-what-does-that-mean/)、[Ryan Williams 公开信串](https://bsky.app/profile/rrwilliams.bsky.social/post/3myspd26qjk2c)、[tensorust 引用图谱](https://tensorust.com/articles/exponential-time-hypothesis-false-openai/)。
**已证实：仓库与 Lean 工程可核查（`ETHIsFalse`、主定理，三公理，8 分钟构建，nanoda 第二内核+Comparator 比对）；有依据：算法正确性未经社区确认，「内部 Claude 模型发现」为自报。**

- 结果比 OpenAI 的**更紧**：#3-SAT 确定性计数 2^{O(n·loglog n/√log n)}，比 OpenAI 的 2^{O(n·(loglog n)²/√log n)} 少一个 loglog 因子。工程也更小：论文+单个 MainResults.lean 陈述层+按章节组织的 proof/ 目录，`lake build` ~8 分钟/24 vCPU。
- 两份独立反驳的意义：单一实验室的 Lean 产物还可能是流水线怪癖；**两家在数小时内各自给出亚指数算法，ETH 为假的后验概率大幅上调**（但最终裁决仍在 Impagliazzo/Paturi/Williams 的独立审查组——他们已声明参与≠认证、无 NDA 无报酬、要求全部原始数据公开+OpenAI 出资办会）。Williams 对 TC 说证明有「两三处外星感（alien-looking）的部分」，认为「每个 CS 人都该给 P=NP 的可能性多加一点权重」，并确认 OpenAI 已自查过密码学影响（认为不直接破任何体系）。附注：**1,871 篇论文引用了 ETH 原始定义文献**——若成立，返工面巨大。
- 最值得玩味的细节：README 给出一段浓缩思路（张量网络收缩+网格上 singlet 分解），称 **Opus 5.5 高推理档仅凭这段描述即可重新导出反驳**（弱一些的 2^{δn} 版本）。也就是说，一旦有了核心 idea，复现证明本身已是前沿模型的廉价操作——稀缺的是「先想到」。
- 优先权争议（定性要准）：Anthropic 数学家 Alpöge 指责的不是 ETH，而是 **Yang–Mills**——称 Ethan Sussman 早已公开沿 Balaban 构造性路线写 YM4（QED3/YM3 已在其 repo），OpenAI 选择抢发而非合作。这与 9 月 Navier–Stokes 争议（Buckmaster/Alpöge vs OpenAI，已有维基条目）是同一模式的第二次上演：AI 数学竞争开始复刻学术界的 scoop 文化，只是按小时计。

**为什么重要 → 怎么做：**对「AI 数学科研流水线」的观察清单加两条实证：(a) **同一猜想被两条独立管线攻陷**是检验「宣称真实」的最强廉价信号——下次再有单家宣称，第一反应该是等第二家/等独立复现；(b) 「关键思想可压缩成一段」意味着问题池里值得追的是 idea 密度而非证明页数。想自己看的：`eth/` 目录 `lake build` 后跑 `PrintAxioms`，与 OpenAI 版对照证明树规模差一个数量级。

## 4. Anthropic 实测「专家会不会服从 agent」：86% 服从了抛硬币决定的倾向——人类复核环节比假设的弱

来源：[Anthropic 研究原文](https://www.anthropic.com/research/agents-judgment-calls)（论文《Who's Aligned to Whom?》）。
**已证实：实验设计与数字公开，预注册合并翻转率 0.72 [CI 见原文]；有依据：单任务单模型一小时场景，外推到你的研究流水线需自行打折。**

- 50 名有因果推断经验的专业分析师（硕博或 6 年+经验占 65%）用 Claude Code（Opus 4.8 高档）做真实统计分析；agent 在四个分析抉择上的倾向由**抛硬币**随机指派（要求「诚实论证、证据要求改判则改、不撒谎」，分析师不知情）。结果：**86% 的抉择与 agent 倾向一致**（无影响基线应为 ~50%）；已表态偏好后被 agent 反对时 **60% 改判**（agent 同意时仅 6% 改）；事后 **77% 的解释直接复述 agent 自己的论据**（有时逐字）；仅凭掷硬币结果可预测 82% 的最终建议。
- 两个常被忽略的对照面：(a) 不给倾向时 Opus 4.8 在 123 次运行中 112 次做出相同选择——**模型有默认偏好**，不指派≠无倾向；(b) 不用 agent 的 11 人里 6 人（55%）犯了使结果作废的方法错误（用 agent 组 3/50），且多花 25 分钟——人不用 AI 更慢更易错，用 AI 则被塑形。两头都不是免费选项。
- 作者自陈局限：刻意强化了倾向、单任务单模型；以及对科学共同体的推论——如果各团队都服从同一模型的偏好，「独立复现」可能不再独立。

**为什么重要 → 怎么做：**这条直接打在第 1、2 条的流水线软肋上：专家复核是整条链里最贵也最被信任的环节，而这个实验说明**复核者很容易变成 agent 论据的复读机**。你的流水线对策要改一层：把「专家先独立给结论，再看 agent 产物」写成强制顺序（研究里先表态者改判率 60% 说明顺序真的重要）；评审问题池时让 agent 对每个选项都给出最强论证而非推荐单一方向；记录哪些决定是你做的、哪些是 agent 倾向渗透进来的——这对「scalable mind 里人类还剩什么角色」是一手实证。

## 8. 科研速递：harness 信息损耗、跨会话记忆、奥赛证明评分、自动形式化（近两周 arXiv，有依据、未复现）

- **[Context Is a Pipeline, Not a Window](https://arxiv.org/abs/2610.36134)**（含复现包）：真实 agent 720 次运行中**三分之一工具结果在到达模型前被 harness 截断**，同一结果里一个字段仅 4.7% 到达率而另一字段 99.3%——截断按 JSON 定长切片，恰好切掉含故障证据的字段；受控实验显示代价先表现为多干活（+43% 工具调用、yield 0.61→0.31）而非答错。**先量化你自己 harness 的信息损耗率，再谈换模型。**
- **[Stratum](https://arxiv.org/abs/2610.36185)**（同组）：给仓库持久记忆而非靠 KV cache（后者每字节贵 10⁴–10⁵ 倍）；跨会话实验中「继承前人笔记」的新 agent 定位根因文件 21/24 vs 纯检索基线 6/24、token 成本中位 -4.5×——**会话间记忆架构是被实证的方向，不是玄学**。
- **[Can LLMs Reliably Grade Olympiad Proofs?](https://arxiv.org/abs/2610.36774)**：USAMO 2025 专家评分数据集+TROJAN 对抗证明生成，前沿模型评分仍有明显差距；MABGrader（把评分重构成多臂老虎机选分）QWK +26.4%。含义直接：你的「agent 批量产出候选→低成本筛」里，**LLM 评分器在奥赛级证明上还不够格当唯一滤网**。
- **[PaperFormalizer](https://arxiv.org/abs/2610.33178)**：LaTeX 论文→依赖图陈述→自然语言忠实度审计→Lean+Mathlib 形式化，**歧义处停下来问作者**——「author-in-the-loop 自动形式化」正是第 1 条 CFSG 人机分工的论文级复刻，可直接抄进流水线设计。
- **[RuHarness](https://arxiv.org/abs/2610.36847)**（Tsinghua 组）：评判标准（rubric）与 harness 共进化——持续从轨迹里发现新弱点并据此改 harness，未见任务上泛化优于固定标准的进化基线。continual improvement 的一个可操作结构。
