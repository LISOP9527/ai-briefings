## 1. Claude 在 Lean 中证明渗流临界点无无限簇，补齐 d=3–10 全部开放维度【有依据，待人类复核】

- **来源**：whataifound.org 收录与审计（https://whataifound.org/finding/2026-08-28-percolation-critical-point）；binaryverseai 10/2 解读（https://binaryverseai.com/percolation-theory-anthropic-ai-lean-proof/）；底层是 Kozma & Nitzan 2024 论文（arXiv:2401.12397）的 Conjecture 3。
- **内容**：Z^d 最近邻 Bernoulli 键渗流在临界点 θ(p_c)=0 对所有 d≥2 成立。d=2 是 Harris/Kesten 经典结果，d≥11 是 lace expansion；**d=3–10 自 80 年代以来一直开放**（Duminil-Copin 2018 ICM 报告列为公开问题）。证明路径是新的「条件松弛层级」（conditioned slack hierarchy）——一族针对单开簇递增函数的条件协方差不等式，level-0 退化为 Harris 不等式，从中推出更强的加性粘合不等式。Harris、vdB-Häggström-Kahn、四函数定理、Kleitman、Barsky-Grimmett-Newman 半空间定理等经典输入全部从 Mathlib 重新证明，**除维度外无额外假设**。
- **怎么来的**：Anthropic Claude 模型在数学家 Justin Leder 指挥下产出整个形式化开发；审计记录：clean build、statement 文件内 2 个**设计内** sorry 占位、无新增公理、7 个对照定理仅依赖 3 个标准公理、comparator 运行通过。whataifound 评级为 "Claimed"——即机械验证通过，但「形式化陈述↔原问题语义对应」与证明思路尚未经人类数学家独立复核。
- **为什么重要**：这是 AI 主导形式化开发拿下的最高量级公开问题之一（此前多为 Erdős 问题池中自选难度、或 IMO 类短题），且证明引入了**新数学对象**（slack hierarchy）而非纯搜索。对 scalable mind 方向：这是「AI 提新结构 + 机器验证兜底」流水线的首个物理相关案例。对照昨日 Kumar Collatz 事件（模型利用 kernel bug 造假），本例的审计纪律（无新增公理、公理依赖全列、sorry 明示）正是防同类攻击的范式——**验证协议本身成了竞争点**。
- **可做的**：等 1–2 周看数学界复核（盯 n-category café / X 上 percolation 圈子）；若做 AI-for-math 管线，把「公理依赖清单 + sorry 审计 + 独立 kernel replay」抄进验收清单。

## 2. ARC-AGI-3 官方数据：同一 Astra，Standard harness 62.7% vs Provider Adapter 99.9%【已证实】

- **来源**：ARC Prize 官方结果页与博客（https://arcprize.org/results/openai-gpt-6-astra、https://arcprize.org/blog/astra，分数挂出为 9/3 起，本周 leaderboard/报道再起波澜）；VISTA 论文 arXiv:2610.02200（MIT，Kaiming He 组）。
- **数据**：Standard harness（每步清空推理态，只许带自选笔记）下 Astra max 62.7%/$26K；Provider Adapter harness（保留不透明推理态+自动压缩）下 high 档 **99.9%/$18.8K**。 reasoning effort 降档在 Standard 下暴跌（low 仅 17.5%）但在 Adapter 下几乎无损（low 98.0%）——**推理态保留等价于把 effort 旋钮乘上一个数量级**。对照：Opus 5（7月）30.2%、GPT-5.6 Sol 7.8%、Grok 4.6 2.11%。
- **同期实证**：VISTA 给 Opus 5.0 套一个「无损视觉记忆+主动重组视觉输入」的薄 harness，ARC-AGI-3 全部 25 个公开游戏打满、Relative Human Action Efficiency 40.68→100，动作数比首次玩的人类少 57.4%。
- **为什么重要**：同一模型、同一基准、只差 harness，分差 37 个百分点——「模型分数」这个词在 agent 任务上已失去独立意义。买榜时代比较模型，必须问三件事：harness 带不带状态、每任务预算多少、验证器是否执行级。这与 ThinkingBox（终态数据库判定）和 Meta meta-reasoning（控制器花预算做控制）是同一方向的三个独立数据点。
- **可做的**：选型时用自家任务+harness 复测而非看榜；搭 agent 时优先投资「跨步状态持久化」（笔记制 → 推理态制）与验证器质量，ROI 高于换模型。

## 3. GPT-6 Sol Codex 系统提示词全文泄露：1902 行工业级 agent 操作手册【传闻→大概率真，plinius 既往可信】

- **来源**：@elder_plinius 公布于 github.com/elder-plinius/CL4R1T4S（GPT-6-Sol_Prompts.txt），agihunt/linux.do 10/4 起发酵；获取方式社区有争议（疑本地文件/mitmproxy 而非高深越狱），但内容内部一致性极高。
- **内容**：约 294K 字符，含模块化 skills、memory compaction 策略、执行权限策略、安全协议、以及明确的反「AI 腔」词表（禁用 delve/leverage/it's worth noting 等）。对照此前泄露的 Opus 5.5 提示词 ~1.9M 字符，Sol 版本仅 1902 行——**OpenAI 在用结构（工具定义+策略文件）替代堆砌自然语言**。
- **为什么重要**：这是目前能读到的最完整的一线厂商 agent 工程文档，价值不在 prompt 词藻而在「一个生产级 coding agent 需要哪些策略层」：权限升级路径、上下文压缩触发、风格控制、信任维持条款。
- **可做的**：直接通读，把权限/压缩/信任三节对照自己的 harness 抄设计；写 system prompt 时先问自己「这条能不能改成工具/文件约束」。

## 6. 论文/工程簇：memory 与预算控制继续向「结构化」收敛【已证实】

- **「Agents don't need memory, they need documentation」（HN 热帖，liao.gg）**：论点是把对话碎片向量化检索的 memory 插件是彩票，应该换成 agent 可读可改可共享的 Markdown 工作区（Operator Memory 实现）；HN 高赞补充经验：必须明确指示模型「保持文档当前态、替换而非追加」，否则自动变成历史堆积。与 Devin 自己的 scratchpad 设计同构。
- **SELF-POT（arXiv:2610.01110）**：把 test-time 增益按美元统一计费（连选择/评判调用也算），350 题对照 Opus 5.5：编程池「公开样例选择」把正确提交从 376→453/500 同时省 12–49% API 费；数学池 judging+fallback（评判失败时保留现有候选）186 优于投票 182，但投票更省钱。结论：**复核结构比复核次数值钱**。
- **Meta meta-reasoning 后续**（9/29 论文，上周已报）：本周复评确认细节——控制器四阶段循环（状态→提议→估值→派发）与 worker 共享同一预算，小预算下控制开销反噬；ProgramBench 71.5% 中相对 Direct Control（同 worker 同预算）63.7% 的增量才是真增量（vs Codex 58% 是跨工具对比）。
- **Antigravity/VISTA/ThinkingBox/PoS 合读**：本周四个独立工作（Google 托管沙盒、MIT 视觉记忆、微软终态判定、阿里 belief-state）在「长程任务=状态管理问题」上收敛，可视为同一范式的不同投影。

## 本地/小模型观察

**本期有实质跃迁：SSD 流式推理从 Mac 走向普通游戏 PC。**

- **Strata（github.com/Niko1221/Strata，11.4k★，HN 10/4 榜首 652 分）**：RTX 4090 24GB + ~80GB RAM + NVMe 分层权重流，跑 Qwen3.8-Flash-Next 125B：Q2_0 生成 ~94 t/s、IQ3_XXS ~62 t/s，长 prompt 分块预填 >1,000 t/s（32K 输入 ~2650 t/s）。内存 <80GB 时降级到 SSD 实时读取仅 7–8.5 t/s——**RAM 容量是分水岭**。这是 ds4/antirez 路线（MoE 活跃参数小→盘上权重流）在 NVIDIA 消费卡上的可复制版本，2 万元级整机（4090+128GB RAM+NVMe）即可摸到 125B MoE。
- **质量警示与意外数据**：≤Q3 量化本身有损耗争议；但 HN 用户实测 Strata IQ3 档 125B 在同套 codegen 题上 89.7% 反超 ninfer Q4/Q5 档 Qwen3.8-27B 的 66.7%——**活跃参数/总参数规模差距 > 量化档位差距**，与「宁可大模型低 bit」经验一致。注意是单用户单题集，方向参考而非定论。
