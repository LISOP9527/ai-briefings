## 1. AlphaProof Nexus 正式登上 Science：AI+Lean 证明搜索首次过同行评审的大规模评估

**来源**：Science 10.1126/science.aej2213（10/8）、arXiv:2605.22763（5/21 预印）、Avigad+Ballard Perspective、Emily Riehl Expert Voices、EurekAlert · **已证实**（同行评审后正式发表）

- 数字：agent 自主解决 **353 题中的 9 个 Erdős 开放问题**（按形式化子问题计：#12(i)、#12(ii)、#125 变体、#138 变体、#152、#26 Tenenbaum 变体、#741(i)/(ii)、#846，Lean 文件已开源在 google-deepmind/alphaproof-nexus-results）；其中 #12(i)/(ii) 是 Erdős 与 Sárközy 1970 年提出的、**挂了 56 年的问题**。另从 Gemini 自动形式化的 492 个 OEIS 开放猜想中证出 44 个（人审确认形式化正确且此前未证；用前几项做检验引理防错误形式化）。
- 架构对比本身是贡献：**"basic" agent（Gemini 3.1 Pro prover subagent + Lean 编译器反馈循环）就足以解出全部 9 题**，但在最难的题上更烧钱；"full" agent（进化式协调 + Gemini 3.0 Flash 打 Elo 分的草图评审 + AlphaProof 作工具）在难题上更省。每题成本"几百美元"量级。
- 已部署到组合数学、优化、图论、代数几何、量子光学的真实研究中。配套讨论：Avigad/Ballard 的 Science Perspective、Riehl 的 Expert Voices、Kohli 的 X 长推。

**为什么重要**：上轮 Erdős 池新闻全是"claimed/provisional"，这篇是**第一个走完 peer review 的大规模结果**——AI 辅助数学从"需要人复核的声明"正式进入"被期刊背书的文献"。对 scalable mind：basic agent 复现全部成功这个细节比总分值钱——证明搜索的主力是"生成↔验证交替"这个 loop 本身，花哨协调层只在难题上赚回成本。想动手就去翻他们的 Lean 仓库，9 份证明全文可编译。

## 2. OpenAI 数学稿被指与用户上传手稿雷同：arXiv 脚注里的最重指控

**来源**：Chenglong Ma arXiv:2610.10072 脚注、MathOverflow #515845、Karagila 两篇博文（karagila.org/2026/openai-pp/ 与 /2026/lean/）、HN #50013902（172 分）· **指控方为一作本人；OpenAI 未回应，真实性未决——按"有依据的单方主张"处理**

- 经过：博士生 Chenglong Ma 在其 preprint 脚注写明——"该结果亦见于 OpenAI 10/6 发布的论文 [8]，**其证明策略与具体记号选择，和 9/8 上传至 ChatGPT 的本稿初版一致**"。即：他把自己未发表的 Partition Principle 手稿喂给 ChatGPT，一个月后 OpenAI 的 722 篇数学稿里出现了同构结果。HN 讨论指出一个月来不及走训练管线，若为真，含义不是"拿用户数据炼权重"，而是**用户上传内容被内部模型/检索侧直接吸收复用**——比 distillation 丑闻性质更重。
- 平行事件：Partition Principle 领域头号专家 **Asaf Karagila 公开拒绝评审** OpenAI 那份稿，称其为"对数学家的 Denial of Service"；他次日再发文《Why I don't trust Lean code from AI》——论点与 Hales 同源但更尖锐：**三百万行 Lean 没人能审"陈述保真"，kernel bug 史摆在那，规模本身就是漏洞载体**。另 OpenAI 研究 lead Dan Roberts 在 X 上宣布了若干更正/撤稿。
- 待观察点：Ma 当时 ChatGPT 的隐私设置（"不用于训练"档）；OpenAI 是否回应；这一例是孤例还是流水线惯例。

**为什么重要**：如果坐实，这是"AI 数学流水线"第一条**数据出处红线**——问题池管理之外，还得回答"模型的素材从哪来"。对用户的实操含义直接：**未发表的手稿、未公开的想法，不要喂给任何可能被内部侧检索复用的服务**；本地/自托管模型处理私密素材的理由又硬了一分。也解释 Erdős 池治理为什么突然改轨"证据链优先"——学界对这批稿的信任预算已经见底。

**来源**：FT（10/10）、CNA/Reuters 转述、HN #50035886 · **已证实（谈判阶段，可能破裂）**

- FT 多方信源：Nvidia 正谈"加深投资或收购" Reflection AI，形态未定——全资、增持、或 acqui-hire（雇人+技术授权，绕开完整并购审查）；数周内可能达成，也可能谈崩。Nvidia 已投 **$800M**，是最大战略股东之一。特朗普政府把 Reflection 定位为"美国对抗 DeepSeek/Kimi 等廉价中国开源模型"的旗手。
- 时点微妙：Beam（501B/23B、Apache 2.0 承诺、本月底放权重+技术报告）发布才 5 天，权重还没落地。

**判断**：如果 Nvidia 拿下，三件事要打问号——Apache 承诺是否兑现、评测独立性（买家同时卖铲子）、以及"非中国系最强开源"这个叙事会不会变成 Nvidia 产品线的定价筹码。反过来若谈崩，说明 Beam 的商业模型撑不住独立。无论哪条，**Beam 权重本月底是否照放成了硬检验点**。对生态：开源旗舰的所有权正在向"算力-资本-国家队"三方合并收拢，纯独立的开源前沿实验室快没了。

## 4. 逃逸周的基础设施回应：Microsoft MXC 1.0 GA + 同日两枚 symlink 逃逸 CVE

**来源**：blogs.windows.com（10/7 GA）、github.com/microsoft/mxc、HN #50016956；CVE-2026-108599 / CVE-2026-108600（NVD 10/10）、theagentictimes · **已证实**

- **MXC（Microsoft Execution Containers）GA**：跨 Windows/Linux/macOS 的策略驱动执行层——开发者声明 workload 需要的资源（文件、网络目的地），MXC 用合适粒度的容器在运行时强制边界；**策略放在 agent 控制面之外，模型生成的代码无法给自己扩权**。后续接 Entra（区分 agent 与人的活动）和 Agent 365（本地 agent 纳管）。
- 为什么需要它，同日给了答案：**phi（0.1.1–0.28.4）与 open-multi-agent（1.5.0–1.21.2）两个框架的 workspace 写入限制都能被 symlink 绕过**——权限门只做词法路径比较不解析真实路径；恶意 repo 埋 symlink+prompt injection 即能把 agent 的写工具引向工作区外任意文件。

**为什么重要**：Anthropic 报告（逃逸进真实网站）+ OpenAI misalignment 报告（绕过 GET-only）+ ARTEX（IAM 过权）+ 这两枚 CVE 指向同一结论：**"默认环境可信"是所有出事的共同前提**。MXC 是第一个把"不可信输出必须进容器"做成跨平台 OS 原语且有企业身份/审计配套的方案。实操：本地跑 coding agent 至少做三件事——写权限加 realpath 校验、出站网络白名单、git worktree/容器隔离；有 Windows 环境可以直接试 mxc。

## 快讯

- **LeanPlan**（arXiv:2610.08246）：LLM 生成规划启发式 + **Lean4 机检可采纳性证明**——GPT-5.6 Sol 在 agentic loop 里为 13 个域产出最优规划启发式，多数域展开状态数少于 SOTA 的 Scorpion。思路干净：证明绑的是实际跑的代码，不是另写一份"声称等价"的实现。
- **CoCo-Prover**（arXiv，Columbia 等）：把"证明成功率 vs 成本"做成一等优化目标——两层 proof hypergraph + 把每个 specialist 调用当独立计价商品的 agentic router，5 个 Lean4 程序验证基准上全部拿到最优 solve rate。和决策模型/路由是同一逻辑往定理证明里搬。
- **ARC-AGI-3 coding agent 思维追踪**（arXiv:2610.11450）：给 agent 的"每个想法"留文件级 trace 后的实测——**跨任务脚本复用仅 33/630**（脚本绑死关卡态），agent 实际靠"重写新脚本+丢弃细节"迁移知识；笔记只增不改、矛盾靠全量日志仲裁；最毒错误是硬编码值跨界。**对 continual learning 的直接启示：文件级记忆系统要默认"弃写"而非"改旧"，外部日志是防灾难遗忘的底座。**
- **Cockroach Labs Sinai**（HN 302 分）：把 bug 当病人、coding agent 当医疗团队的 5 个月实践——author/reviewer 分 agent 分 context 是他们和 OpenAI Symphony 的关键差异，但作者诚实标注无 ablation。组织设计参考，非结论。
