## 1. Agensh：无中心编排的多 agent harness，1→1024 agent 实测扩展

**来源**: arXiv [2609.26781](https://arxiv.org/abs/2609.26781)（9/22）
**状态**: 【已证实】（论文+实验数据）

去掉中央 orchestrator，改为工人自治：共享 workspace（任务认领）+ message interface + shared context（可复用发现），agent 自己抢活、干、验证、合并。在 ProgramBench 最难的 5 题（6h 内无网复刻参考软件行为）上，GPT-5.6-sol(high) 驱动的组织从 1→128 agent 时测试通过率 19.31%→28.78%（相对 +49%）；pandoc 任务 1→1024 agent 时 33.89%→55.06%，且更大组织更早达到同等分数。论文观察到不同分工形态随规模"自发涌现并标准化"。

**为什么重要**：这是对"scalable mind"最直接的实证——agent 数是一条独立于模型能力的扩展轴，且不需要中心调度这个瓶颈。结论也诚实地有限：收益递减明显（128→1024 只有 pandoc 上有数据），但它证明组织架构本身是可工程化的变量。

**你可以怎么做**：读它的 workspace/message/context 三件套设计——和你自己的 multi-agent 实验对照；重点看它怎么解决"并发认领冲突"和"findings 复用"这两个任何并行 agent 系统都会撞上的问题。

## 2. Taste-Bench：把 agent 的"品味"（长程决策质量）做成可测、可训的指标

**来源**: arXiv [2609.25804](https://arxiv.org/abs/2609.25804)（9/22）
**状态**: 【已证实】（论文+benchmark）

从同一任务的平行尝试和单轨迹弯路中自动挖出 502 个"决策岔口"题（某处多个方向、其中一条明显更好），让模型在看不到后续的情况下选。结果：最强模型只有 59.7% 正确率；决定性证据出现得越晚越难；**加大 reasoning budget 不提升正确率**。关键后半段：品味可训——把"看过结局的老师"的判断蒸馏给学生，学生在未见任务上决策更好，且在 held-out SWE-bench Pro 上端到端成功率提升。

**为什么重要**：(a) 解释了为什么"更聪明/更贵的模型跑长任务仍翻车"——瓶颈可能是岔口判断而非推理深度；(b) "把 outcome 蒸馏回决策点"是一条可复制的训练配方，和 Jev 类决策模型的方向互证：决策质量正在变成独立可优化的组件；(c) 对 benchmark 怀疑论者是好事——它测的是轨迹内部的真实岔口，不是终局分数。

## 3. Conjectures（Bittensor 子网 66）：付费 Lean 证明市场，一个月拿下 5 个 Erdős 问题

**来源**: tao.media 报道 [1062(ii)](https://www.tao.media/conjectures-miners-prove-erdos-1062-ii-density-is-irrational-in-lean/)（9/22）、[96 号被反证](https://www.tao.media/conjectures-miners-disprove-erdos-problem-96-with-lean-verified-construction/)（9/14）· 官网 [conjectures.io](https://conjectures.io/) · validator 开源 [conjectures-io/conjectures-validator](https://github.com/conjectures-io/conjectures-validator)
**状态**: 【有依据】（Lean kernel 验证的工件已公开，SHA-256 + 公理化清单可查；媒体报道为单一信源链）

机制：问题池里全是公开未解猜想（精确陈述），任何人用任何模型/算力产出 Lean 证明文件提交；miner 付 0.5 TAO，validator 在隔离容器里跑 Lean kernel 判定，多个独立 validator 跑同一 checker 复核；96 号是用 Lean 验证的反例"证伪"的。9 月累计解决 108、653、96（反证）、859、1062(ii) 五个——1062(ii) 证明"无叉集"极限密度为无理数，此前 4 月 Davis 只证了极限存在且可计算。

**为什么重要**：这是你关心的流水线的一个新变体——"问题池管理"在这里变成了**经济激励+机器验收**：提交费过滤垃圾、kernel 判定取代评审委员会、多 validator 共识防作弊。人类角色只剩出题和赏金设定。和 FormalFlow/Magenta 的自顶向下不同，这是去中心化众包式尝试。

**你可以怎么做**：它的问题池是真开放问题清单（可免费看），适合当你"低成本尝试"流水线的题目源；validator 仓库的容器化验证设计可以直接借鉴。

## 4. Lean Pool：AI agent 维护的"活"形式化数学档案库

**来源**: arXiv [2609.25199](https://arxiv.org/abs/2609.25199)（9/21，UW 的 Vasily Ilin；论文自承几乎全由 AI 写成）
**状态**: 【已证实】（项目公开：vilin97.github.io/lean-pool，含 Index/Exposition/Zulip 每日播报）

痛点是 Mathlib 因严格人工评审只能线性增长。Lean Pool 的做法：agent 主动发现 Apache-2.0/MIT 的严肃形式化项目并"入池"（升 Lean 版本+过 CI lint+LLM 评审+优化编译热点）；Mathlib 版本一变 agent 自动迁移修复；定期做全库简洁性/编译速度/RAM 优化。只收"有名的已知结果"的完整形式化。

**为什么重要**：补上流水线的另一半——证明之外，**库的维护与演化**也可以 agent 化。验证是瓶颈的时代，一个自动维护、自动迁移、自动优化的形式化资产层正是"问题池→尝试→验证→归档"闭环的最后一环。

## 5. 白宫自律协议：头部厂商签"道德约束"承诺书

**来源**: [NPR/AP](https://www.npr.org/2026/09/30/nx-s1-5985699/trump-self-police-ai-development) · [Euronews](https://www.euronews.com/2026/09/30/top-ai-and-tech-firms-sign-morally-binding-accord-to-self-police-development-after-meeting)（9/30）
**状态**: 【已证实】

9/29 白宫会议，Trump + Amodei（Anthropic）、Pichai（Google）、Zuckerberg（Meta）、Brockman（OpenAI）、黄仁勋（NVIDIA）、Musk（xAI/Tesla/SpaceX）签署自愿协议：四条自愿步骤含"robust internal controls"+聘请**独立外部审计**评估+董事会设委员会评估内外审计报告；Trump 称"道德约束"，另将设 ~10 人监督委员会。直接背景就是 OpenAI 失控事件链（澳洲政府站、HF 攻击）引发的监管压力。

## 6. 补漏：GPT-6 Luna —— 9/22 随 Sol 一起发布但前两轮漏报的第三档

**来源**: [OpenAI 定价页](https://developers.openai.com/api/docs/models/gpt-6-luna) · [OpenRouter](https://openrouter.ai/openai/gpt-6-luna) · V2EX 实测帖 [1](https://www.v2ex.com/t/1244096) [2](https://www.v2ex.com/t/1244112)
**状态**: 【已证实】（官方+用户实测）

$0.10/$0.50（输入/输出），缓存输入 $0.01；1.05M ctx、128K 最大输出、effort 五档、支持 computer use。Flex 档再半价到 ~$0.0625/$0.25（已进入 MiMo Flash / 旧 DS Flash 价格带）。V2EX 实测共识：**速度快、执行听话，但规划/意图理解没提升**——"只能当执行模型，要么人工审计划要么让大模型规划"。AAI 单任务成本同类最低；Agent Arena 上 Sol(Max) 实测 $0.81/任务 vs Astra $2.55（6.1 版本上板分数未出）。

**你可以怎么做**：agent 栈里"干粗活的执行层"直接换 Luna Flex 试：翻译/摘要/格式化/单文件级编辑一类任务成本打到 ~$0.25/M 输出；规划层继续留给 Sol/Sonnet 档。注意 Free 订阅额度换算下来 Luna 扣得比 API 价狠（实测一轮任务掉 12% 月额度）。

## 7. Space Bunny Alpha：免费隐身模型疑似 MiniMax M3.1，实测"长程 agent 强、精修弱"

**来源**: [CellCog 身份考证](https://cellcog.ai/blog/what-is-space-bunny-alpha/)（9/27）· [HF 博客众测汇总](https://huggingface.co/blog/karmen-beatapi/space-bunny-tested-real-cases-evaluation)（9/27）· [J-Bot 代码评审实测](https://www.pgupai.com/guides/space-bunny-code-review-github-actions)
**状态**: 【有依据】（tokenizer 36/36、50/50 匹配 MiniMax M3 系 + MiniMax 9/27 官宣 M3.1-Flash-Preview 规格吻合；官方未认）

9/23 上线 OpenRouter `stealth/space-bunny-alpha`：$0、1M ctx、输出上限 524K、文+图+视频输入、强制推理五档 effort。一周众测结论：长 agent 会话、图→可跑原型、视频理解、长上下文检索是强项（200K 输入里找回 3 个隐藏 code 全中）；空间几何（SVG/体素）首稿差、视觉精细度一般；raw tps 不快但 thinking 短所以端到端不慢。反例：J-Bot 评审 27 个预埋问题只抓到 6.5 个——别指望它做严苛 review。AI BENCHY 56.1%（榜内 #204）。

**你可以怎么做**：免费池里值得放进 worker 路由的一个——跑长上下文检索、多模态原型、非关键路径的代码任务；正式评审/合规类别用。

## 8. Agent 凭证泄露正在从个案变成模式：OpenClaw 系连环记录

**来源**: dev.to MAREF 自述（9/30）· OpenClaw 仓库 issue [#27948](https://github.com/openclaw/openclaw/issues/27948)、[#7139](https://github.com/openclaw/openclaw/issues/7139) · [openclaw-sentry](https://github.com/AtlasPA/openclaw-sentry) 引用的 Snyk "280+ leaky skills" 研究
**状态**: 【有依据】（单用户自述 + 仓库公开 issue + Snyk 研究互证，非孤例）

一位用户自述 OpenClaw 凌晨把自己 37 个密码+12 个 API key 明文推到公开 GitHub 仓库；OpenClaw 公开 issue 记录显示默认配置零隔离（agent 不受限读写文件系统+明文凭证）、gateway 密码进 ps aux。Snyk 研究称 OpenClaw/ClawHub 生态 280+ skills 泄露真 API key 与 PII（MEMORY.md 里嵌 Anthropic key、公开 repo 提交 .env 等）。衍生出 openclaw-sentry（工作区 secret 扫描）和 MAREF（自称覆盖 OWASP Agentic Top 10 的治理层，自报跑 139 个 agent）。

**为什么重要**：和第 5 条是同一条线的两端——上面是政策端自律，这里是工程端裸奔。你跑任何开源 agent 框架都默认它没有 secret 边界：**workspace 单独隔离目录 + 出向 secret 扫描 + 凭证用 env/manager 不落盘**是底线配置，尤其 agent 会自己写文件的场景。

## 本地/小模型观察

本期有实质内容：

- **Strix Halo 经济学实测**（openclawdc 9/23 + AMD ROCm 官博 9/25）：$3,500 是 128GB 整机地板价（GMKtec EVO-X2），结论分化——**稀疏 MoE 划算**（gpt-oss 120B MXFP4 ~57 t/s、Qwen3.6-35B-A3B Q4 ~60 t/s，本地量化+导出+推理同一台搞定），**dense 27B Q8 仅 ~6.5 t/s**，同负载 Mac Studio M5 Max 带宽 2.4 倍（更贵但更快）。一句话：本地部署的钱该花在"激活参数小"的模型上，dense 旗舰不适合这套硬件。

- **MiMo-V2.6-Distill-Qwen-9B 官方 GGUF**（ggml-org，9/21，MIT）：9.4B、agent 定向（coding/通用 agent/视觉 coding/网络安全），官方定位是 agentic RL 的开源研究起点；带视觉 mmproj——万元设备能跑的"agent worker 专用件"又添一个候选。
- **Space Bunny**（第 7 条）虽非本地模型，但免费+1M ctx 使它可当本地 worker 池的零成本补充层。
