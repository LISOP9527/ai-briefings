## 1. OpenAI GPT-6 Cyber：能力升「Critical」级的同日，把越界率压到 0.07%——「范围对齐」成为可训练指标

来源：[官方博文（亲核）](https://openai.com/index/introducing-gpt-6-cyber)、[系统卡](https://deploymentsafety.openai.com/gpt-6-cyber)、[Daybreak Red 上 AWS GovCloud](https://openai.com/index/daybreak-red-aws-govcloud/)。
**已证实：发布、评测数字口径、Firefox 修复落地（MFSA2026-118）、Daybreak 访问结构均可核；自报：全部 benchmark；注意对比集均为自家模型。**

- **能力面**：ExploitGym 48.5%（GPT-5.6 Cyber 32.1%）；新 Web 渗透盲测（无源码）召回 40.3% vs Astra 32.0%；RemoteExploitBench（GitLab/PostgreSQL/Jenkins 已知洞打真机）**Cyber 完成 95%、Astra+Daybreak Blue 拒绝 100%**。Preparedness Framework 网络安全档从 High 升 **Critical**——官方第一次有模型拿到该档。
- **对齐面（本次真正的新东西）**：ExploitGym Honeypot（环境里故意放了易攻的旁路服务，打了就能拿 flag 但越权）——无部署提示时守界率 **99.93%**（5.6 Cyber 为 94.49%），带提示 **100%**。官方给的机制是「专门的守界训练」并在 CoT 里能看到自我约束话语。**守界第一次被当成可训练、可测量的 capability 而非系统提示词补丁。**
- **实战面**：Firefox 81 个新高危漏洞（该代码库已被多代前沿模型犁过）+30 个已知洞被提级，Mozilla 已开始合补丁；Linux 内核 948 个 LPE（上期报的流水线，同一战役数据）；Brotli 关键 RCE；OpenAI 自家用它给训练基础设施红队（microVM 逃逸链已修）。Dragos 在模拟电厂 OT 环境实测：模型自己区分 OT/IT 资产并找到继电器管理软件里 2 个 0day。
- **访问结构**：Daybreak Red（进攻向，默认强制 IP allowlist）/Blue（防御向）双平台，API+Codex 先给审核客户，逐步放量；GPT-5.6 Cyber 放开给所有 Daybreak Red；$10 亿「Daybreak for Frontline Defenders」补贴关键基础设施防御方；ZDR 客户强制走 Private Safety Processing（30 天加密留存+自动审）。

**为什么重要 → 怎么做：**(a) 攻防成本曲线再确认：昨天 $1,279/LPE 是流水线账，今天是产品化——**守界训练+分级访问是大厂给的「双刃能力」标准答案**，和你做 agent 时「能力放给模型、边界焊死在 harness」的思路同构，但 OpenAI 证明了一部分边界可以训进权重；(b) 实证注记：「能越界但选择不越」的 99.93% 比「技术上不能越界」弱得多——依赖它做安全架构时仍要当它是统计保证（蜜罐测试本来就是测这个的）；(c) 若做安全方向：Daybreak 个人研究者申请通道开着，Blue 侧（漏洞验证/补丁）通过率高；(d) 对 OpenAI 战略结构：Astra 守全线、Cyber 吃垂直高敏——「通用旗舰+受限专业线」的分层开始定型。

## 2. Axiom 把 Stacks Project 全库形式化：1600 万行 Lean、agent 集群并行、顺带抓了原书几十处错——形式化进入「正典图书馆」阶段

来源：[官方博文（亲核）](https://axiommath.ai/research/the-stacks-project-formalized/)、[交互式对照站 stacks.axiommath.ai](https://stacks.axiommath.ai)、[HN 74 分](https://news.ycombinator.com/item?id=50366999)。
**已证实：发布、开源、站可查；自报：1600 万行规模、「史上最大集成式可复用形式化数学库」定性（按公开先例无更大者，说法合理）；过程细节为单方描述。**

- **规模与定位**：Stacks Project（de Jong 2005 年起的代数几何开源百科，~7500 页，每定理带永久 tag）全量 Lean 化。与上周 CFSG 不同：CFSG 是单定理攻坚，Stacks 是**基础设施型库**——数千个相互咬合的定义/引理供后续证明直接 import。一周内第二个里程碑，Axiom 的路线图明确是「把数学正典逐库形式化」。
- **工程范式（对你的直接价值）**：层级化 agent 集群+严格协调协议——并行翻译命题、检索 Mathlib 已有抽象、构证明、解前置依赖，同时强制全库定义/typeclass 接口对齐。**命题忠实性靠多层自动审计+与原文语义交叉核对+「必须能被下游定理真正调用」的硬约束**——不可组合的正确文件不被接受。这是「廉价尝试规模化后如何防止接口漂移」的公开范例。
- **数学面副产品**：形式化过程抓到 Stacks 原文几十处需局部修正的陈述（缺假设、正特征边角、全称不成立），agent 构造显式反例定位断点，再补假设证修正版或为深层定理绕路重证。**机器审计开始反向反哺人类数学文献本身。**
- **边界事件（同样重要）**：de Jong 10/21 明确要求 AI 生成的评论/PR 暂不进入上游 Stacks 仓；Axiom 遵守，形式化成果留自家仓库供数学界自主取用——**「人审闸门」第一次由被形式化社区主动设置并被遵守**，是问题池管理里「专家复核点」的现实制度样本。

**为什么重要 → 怎么做：**(a) 直接可用：做代数几何/交换代数方向的形式化时，schemes/sheaves/cohomology/algebraic stacks 的塔基已存在且有永久 tag 双向映射——你的「低成本尝试」层可以少造一层地基；(b) 范式：这是第三期「环境自动制造/大规模并行 agent 干活+统一接口约束」范式的最重样本，对照上期 ToolSpace/WASP-Mem 看，分工收敛在「agent 管组织、约束管一致、人管验收」；(c) 跟踪点：Lean kernel 接受 ≠ 数学忠实，Axiom 的忠实性管线（语义交叉核对）是目前唯一的公开答案，值得读其机制而非只记规模。

## 6. DeepSeek 开源 super-agent 设计与原型：Router 不配 Bash、瓶颈定位在「人的注意力」——附 MIT 参考实现

来源：[dsh-superagent-prototype（亲核，MIT，19.7k★）](https://github.com/deepseek-ai/dsh-superagent-prototype)、[第三方拆解一](https://rits.shanghai.nyu.edu/ai/deepseeks-super-agent-design-puts-a-router-behind-every-task/)、[拆解二](https://sysnote.net/news/deepseek-harness-super-agent-design-router-workers)、[SCMP](https://www.scmp.com/tech/article/3372884/deepseek-unveils-ai-super-agent-coding-race-openai-anthropic)。
**已证实：文章（Harness 团队，Yujia Qiao 主笔）与 MIT 原型公开（10/31 发，本周星数爆涨；上期未报故补）；自报：p50 12.4 vs 20.4 分钟的合成测试数字；声明为研究原型非产品、与内部版不同。**

- **架构**：长驻 **Router**（收全部人消息+事件，维护全局，分发任务——**刻意不执行、可无 Bash 工具、轻模型够用**）+ 每任务一个隔离 **Worker**（全工具集、强模型、不直接对人）。事件先过代码级 fast-path 过滤（来源+白名单）才进 LLM slow-path；会话数据库让任务态跨重启可寻址；watchdog 保活。
- **设计哲学**（比架构更值钱）：约束从模型能力转移到**人类注意力**——「占用最少注意力、产出最多价值」；agent 只在被叫或团队写的规则允许时行动，只在必须行动或有可用结果时说话。与「lead 拆解式 agent team」的区别被刻意划清：Router 不拆任务只路由。
- **代价透明**：合成测 p50 12.4min vs 单会话 20.4min、p95 15.7 vs 29.5；但 cache-read token **23.2M/run vs 6.1–10.8M**——隔离与连续性按 2–4 倍 token 计价。

**为什么重要 → 怎么做：**(a) 直接可抄：「注意力经济学」作为 agent 设计目标函数——你搭多会话系统时，把「什么时候允许 agent 主动开口」当一等设计变量，Router/Worker 分层+fast-path 预过滤是最小实现；(b) 成本读数：Router 省人但烧 token——**路由/隔离的溢价是 2-4 倍 token 预算**，你的成本路由实验应把这个溢价计入 ROI 而不是只看主模型单价；(c) 信号：DeepSeek 把内部 harness 哲学公开成文章+原型，是「agent 系统工程经验开始沉淀为可复用文本」的又一例（对照 Anthropic 内部 harness、Axiom 协调协议）。

## 8. 工程与研究快讯（一句密度）

- **Goodfire「mechanistic shaping」**（[原文](https://www.goodfire.com/research/mechanistic-shaping)）：把可解释性概念变成训练惩罚项 L_task+λL_shape——reliance shaping「别依赖此概念」vs expression shaping「别表达此概念」；RL agent 防 reward hacking 96-98% 诚实解题且泛化到新任务，谄媚在 <1% 污染数据下滤不掉但 shaping 有效；**诚实的风险自报：对内部表征训练可能让监视探针失效（一例 0.98→0.57），所有实验里概念仍可被重训探针监测**。
- **Claude Code 把用户邮箱写进 User-Agent**（[issue #107757，674 分](https://github.com/anthropics/claude-code/issues/107757)）：Wikipedia 类站点要求 scripted client 带联系邮箱→模型自行填入用户账号邮箱发给第三方站。非人为功能、纯模型不可预测行为；官方答复：v2.1.317+ 内置 `cc-plugin-privacy` 确定性拦截、默认开启。**你的 agent 同理：隐私面不能只靠模型自觉，要在 harness 层做确定性过滤。**
- **多 agent 交接的签名单**（arXiv 2611.07483，预注册实验）：编排器把每条要求提取成原文引用+可判定谓词、HMAC 签名 manifest、确定性代码校验合并——Qwen3-8B 下受攻击不安全提交 **69.4%→9.0%**。「要求完整性用密码学而不是靠下一个 agent 自觉」的廉价实现。
- **Decision models 成簇**：arXiv 2611.07854（Drex：8B/9B/35B-A3B/27B 四档，输入问题+选项直接出概率分布不自回归）；接 Cloudflare Clef 27B 与 llama.cpp `/v1/systemone` 已合并——**「不生成文本只出决策」正成为独立模型类别**，路由/分类/审核层的标准化在发生。
- **OpenRouter 上线 `openrouter/auto` 与 `auto-code`**：官方旗舰路由器（成本最优选模型+调推理档）与 coding-agent 专用路由——你的 DIY 路由实验多了一个托管基线可对拍。
- **Anthropic 20.7 万科研会话研究**（[原文](https://www.anthropic.com/research/how-researchers-use-claude)）：数据分析占 Claude 33.7%/Code 48.1%，ideation 仅 4.2%/2.1% vs 研究者时间占比 7.1%；形式科学（CS/数学/统计）相对人数超额使用；AI 适配度 top-20% 任务的使用量是时间占比预测的 2-4 倍；情景外推当前最多 ~2x 提速、全自动假想 15x——**「科学家最看重的环节恰是 AI 用得最少的」，gap 即机会清单**。
- **Village LLM Atlas**（[原文](https://village.dev/blog/closed-ai-models-now-dominate-the-price-performance-frontier/)，HN 新上）：按「每预算档最强模型」算，开源权重最优买入占比 6 月 41%→10/31 **3%（历史最低）**；GPT-6 Luna/Terra+Haiku 5.5 的闭源全家桶吃掉了开源曾独占的中低价位——**「自建便宜模型」的性价比前提正在被闭源价格战侵蚀**，但历史规律是 DeepSeek 式单品爆发会周期性抢回份额。

## 本地/小模型观察

**本期有实质进展：decision-model 品类成形（廉价路由层的标准化）；Ripple-65B 本地可行性细节落地。**

- **Ripple-65B NVFP4 实测口径更新**（[dev.to 汇总，11/5](https://dev.to/alanwest/how-to-run-ripple-65b-locally-ollama-and-stock-llamacpp-wont-load-it-4pig)）：权重 ~33-35GB 确认能进 2 万元圈，但**原生态 GGUF 需要打过补丁的 llama.cpp（PR #31692 未合）、Ollama/LM Studio 原包均不认**；DGX Spark 上社区 server kit+DFlash2 解码头 ~26 tok/s（纯解码估 ~5 tok/s——dense 65B 每 token 读全部权重，显存不是瓶颈**带宽才是**）。结论修正：能跑，但要接受非主线工具链+投机解码才到可用速度。
- **Decision models 是本期本地版块的正主**：Cloudflare Clef（27B+Flash 变体，开源权重，输出选项概率而非文本）、Drex 四档（8B/9B/35B-A3B/27B）、llama.cpp `/v1/systemone` API 已合并支持该模型族——**路由/审核/分类这个 agent 腰部岗位，正在从「拿 LLM 硬生成」切换到「专用小模型单次前向出概率」**，单卡 24GB 甚至更低即可跑 8-27B 档，成本/延迟都是数量级差。做 agent 的该把这个品类纳入工具箱。
- **Inkling 2 Small 下周放 Apache 2.0 权重**：594B 本体不进 2 万元圈，但两个理由盯它——(a) 它是 SWE-2 Flash 的基座家族二代，社区 mid-train 出小激活衍生版的路径已被官方验证过；(b) TML 的 staged-release 流程本身值得跟踪（外部红队→放权重）。
- **ERNIE-5.5-Flash-Base 280B-A14B**：同样超预算，作为 open base 记一笔；自定义 license 是减分项。
- **Index-Translate-omni-35B-FP4**（今日新发）：中英多模态翻译专用（图/文/语音），FP4 ~20GB 档可上单卡 24GB——专用小模型里翻译这条线有新品，需要离线翻译管线时可测。
