- **ERNIE-5.5-Flash-Base**（百度，11/8 HF）：280B/14B 激活 MoE 预训练 checkpoint，33.5T token，128K 训练 1M 推理，FP8+BF16，自报五项基础指标超 DS-V4-Flash-Base——**纯 base 开放权重**（自定义 license），是微调研究的原料而非可用产品。
- **Co-Design Bench**（阿里等）：真实编码会话的用户修改请求出题、含图/音/视频输入——GPT-6 Astra 平均满足 ~70% 要求但**仅 26.4% 任务全对**，Opus 5/Qwen3.8-Max 随后，Grok 4.6 垫底；「满足度 vs 全对率」的断层是比总分更诚实的读法。
- **Beneath the Surface**（USTC，arXiv 2611.07624）：审计 4 种 harness 自进化方法——16 个进化 agent **全部**出现「新增覆盖任务同时丢失旧覆盖」，最高分者并非均值提升最大者，更严准入反而丢掉有用变体；EvoAudit 修正选择-分析-变异-门控后最优——**无权重 RSI 的第一个系统性负面证据，「越进化越窄」需要主动防护**。
- **Meta ABTest Agent 论文**：LLM 只选/排实验步骤，数字全交确定性工具，每张表可回溯到代码，知识库只收专家审核文档——**「LLM 编排+确定性计算+专家复核知识库」三段式又一个大厂范本**，你的流水线可直接对表。
- **OpenFrontiers**（UIUC Tong Zhang 组，arXiv 2610.37739，补上期漏检）：12,151 条跨学科开放问题语料+200 题 Lean 校验 benchmark；七个 agent 在 HQ-50 上闭卷重解已解决题 ≤7/40，联网成功基本是检索——**「开放问题池+可机检评分」的社区版底座**，与你的问题池设计几乎同构，先看它再自建。
- **TB-MathModel**（IDEA FinAI，arXiv 2611.08237）：18 道 CUMCM/MCM 真题进容器化终端，624 条 Lean 义务+程序化不变量硬门控（不可行解直接清零），对着多篇获将论文多参照打分；最强模型 O-Eval 64.58% vs $2.54 开源模型 59.81%（1/100 成本）——**建模类任务的性价比断层**。
- **WSP 系统研究**（arXiv 2611.09382）：16 条编辑轨迹×7 基准×0.8B/9B——改 1,023 个参数 MATH-500 +29.45pp，跨任务迁移不均，6/16 轨迹在无法可靠验证时选择不改——**weight-space programming 一周第三个数据点**，「知道何时不改」是可用性的分界线。
- **Harness-S**（SJTU，arXiv 2611.04277）：base harness 全失败的样本才调用兄弟 harness 池出轨迹做 RL——**「harness 多样性当训练资源」**，AppWorld/SWE-Gym/DBBench 上回原 harness 仍显著受益。
- **Andy Hall（Anthropic）审计员实测**：LLM 审计员在 MALT/R-Judge 上能抓多数失准但误报过多——agent 审计的瓶颈从召回转向精度，与 TraceMRT 攻防同读。
- **Calegari（芝加哥）谈 AI 时代数学人才**：批量证明时代招聘应重研究愿景+面谈表达，轻书面产出——对你的长期路径是直接参考信号；同观点 Strogatz 已先行。
- **杂项**：Preferred Networks 开源 PLaMo 3.0 Fin（日本金融特化小模型，<¥1B 营收免费商用）；Salesforce 论文称多领域 RL 专家模型合并比蒸馏省 42% 算力且更优；腾讯元器智能体平台停服（导出窗口至 2027-01-09）；Sutton「苦涩教训 2.0」：算力不够、需要新方法——观点级；Perplexity 队友产品「Teammates」、Karpathy 3 分钟生成 TristanTube 续证「周末项目早餐化」；Qwen4「next week」窗口（11/2–8）已关闭未兑现，预告海报"The becoming begins"两天两百万浏览，QoDuck 灰测继续；Fable 5.5/Opus 5.6 传闻指向 11/10 与 IPO 路演联动——明天是关键观察窗。

## 本地/小模型观察

**本期有实质进展：NVIDIA Dory1.0-4B 开源「循环推理」——用循环层数换智能而非用 token 换，GGUF 可跑；Qwopus 27B 编码新微调；1.7B 搜索子代理展示「单一职责小工」的可行形态；WSP 论文给「改权重修模型」补上能力边界。**

- **Dory1.0-4B（[HF](https://huggingface.co/nvidia/NVIDIA-Nemotron-Labs-Dory1.0-4B-GGUF)+[论文](https://arxiv.org/abs/2611.03998)，10/16 发、本周 llama.cpp 教程出圈）**：looped/latent-recurrent nGPT——输入 8 层+共享循环块 20 层+输出 8 层，循环块可变次数复用，**一个 checkpoint 服务多种推理预算**；6T token 预训（前 4.5T 全 NVFP4）+难度感知循环课程 RLVR。自报：≥2 循环均值超 Qwen3.5-9B/Gemma4-12B/Gemma4-26B-A4B；4 循环在 agentic 任务**少生成 1.3–2.5× token**（算力花在潜空间而非输出上）；只缓存末轮 KV，任意循环数下 KV 占用等同非循环模型。BF16/MXFP8/NVFP4/GGUF 全量开源（OpenMDW）——**test-time scaling 的第二条路径（深度循环 vs 长 CoT）第一次有完整开放实现**，2 万元设备随便跑，值得进你的对测池看「同样题 latent 推理 vs token 推理」的边际性价比。
- **Qwopus3.8-27B-Coder-Flash（[HF](https://huggingface.co/Jackrong/Qwopus3.8-27B-Coder-Flash)，11/8，GGUF 已出）**：Qwen3.8-27B 编码向微调，定位 agentic/tool-use/高效推理——27B 甜点档补员，dev.to 横评里 27B 仍是本地综合最优档，可作为 minicpm-v-4.7-35b 之外的新对照。
- **Obsessive-1.7B（r/LocalLLaMA，11/7）**：LFM3-1.7B+LoRA(r16) 训成单一职责 web_search 子代理——一次搜索→短答案+逐字引文+URL，找不到就说没有；作者诚实给出 50% 命中率/10% 幻觉/5.1s 中位（4060 笔电）——**「大模型管编排、微模型管单工」架构的最小可行样本**，1.1GB 任何设备可挂。
- **TwIL-8B（[HF](https://huggingface.co/webAI-Official/TwIL-8B)，Granite-4.2-8B 全参 SFT+GRPO）**：自报 MATH-500 98.2、AIME2025 88.3、LCB 81.6，IFBench +9.9 vs Qwen3.5-9B；知识类（GPQA/MMLU-Pro/HLE）落后——**非商用 license**，做题型本地 worker 备选，不能进产品。
