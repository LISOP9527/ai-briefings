## 1. KLS 猜想一周内被独立证明三次——三场证明都走了"人类+前沿模型"管线

**来源**：arXiv:2610.01447（Song–Zhang v2）、arXiv:2610.05474（Bizeul–Klartag–Lehec）、arXiv:2610.07728（Balasubramanian–Kasiviswanathan）、Nicolas Brosse 复盘站 human-ai-mathematics.github.io/kls-conjecture-search（10/9）· **有依据**（论文在库可查；正确性待数学界复核，但作者含解决 slicing 猜想的 Klartag/Lehec，先验可信度高）

- KLS 猜想问的是：各向同性 log-concave 测度的 Poincaré/Cheeger 常数是否有与维数无关的普适界。它是高维几何近几十年的引擎问题，与已解决的 slicing、thin-shell 猜想同族。
- 时间线：Song–Zhang 先把界压到 \(C\cdot 16^{\log^* n}\) 并提出高阶 tilt-average 判据 → v2 直接给 \(O(1)\) 界（10/4）；同日 BKL 给"最后一步"版本（10/4 提交）；BK 用积分算子+stochastic localization 给出第三条路线（10/6）。一周内三条独立证明收敛。
- Brosse 从 6 月起用 AI agent 搜同一猜想作为"如何信任 agent 产出"的试验场；猜想被别人证出后，他把三份预印本各自在两日内重建成自己的认证格式并交叉比较——**机器产出 → 独立 agent 复建认证 → 人类可读对照**这条流水线跑通了。
- 据 Brosse 的复盘，三个团队都使用了前沿模型辅助。注意 Song–Zhang 团队一向以高频产出+AI 协同著称，这条"AI 参与度"目前主要依据 Brosse 的记述，论文本身的署名仍是人类。

**为什么重要**：和 openai/math 的"倾泻式宣称"是对照实验——同名问题、同期、传统论文形态、作者自负声誉、互相独立。scalable mind 视角下真正的信号是**证明验证的周转时间**：Brosse 的 agent 两天内能独立复建认证一篇新预印本，验证成本正在逼近产出成本。

**你可以做的**：读 Brosse 的站点（人写、很短、方法论密度高）；三篇论文只需读 BKL 的 introduction——它把 Song–Zhang 判据怎么被用上讲得很清楚。

## 2. openai/math 第一批撤稿：符号错误击穿 3 篇，人类数学家抓出来的

**来源**：github.com/openai/math history.md、@danintheory（Dan Roberts，10/8）、HN #50002650 · **已证实**

- 10/8 仓库更新：新增 6 个 Lean 形式化、19 处修改、**3 篇撤回**——《Algebraicity of Weil classes on split abelian eightfolds》《Kuga–Satake 对应 for K3 曲面》《K3 曲面乘积的有理 Hodge 猜想》。一个符号错误破坏了 stabilization-trace 消去论证，连带依赖该构造的两篇一起死。撤稿文件保留 gap 说明+归档链接。**错误是真人数学家发现的，指出后 GPT Astra 确认不可修复。**
- 现状：top-line 结果 ~42% 有 Lean 形式化。whataifound 对 QRH（Re(s)>7/8 无零点）和整个集合均评级 Claimed——**零外部复核完成**。HN 评论区重要澄清：QRH 用的是 mathlib 标准 RH 陈述（没有自造定义偷换），但 ζ 无零点证明里的某些假设在"扛重活"（如查表项），需要复核是否真的在复杂度界内。
- 对照证据：arXiv 2608.14673v3 对 OpenAI 8 月那批"十大成果"做了人审——**主结果暂无实锤数学错误**，但部分依赖只被部分核过。这给 722 篇的存活率一个粗略的乐观先验，但不是证明。
- 抵制侧：AHM（Association for Human Mathematics）发正式声明称此次发布"不是学术行为而是力量展示"，呼吁数学家停止与 OpenAI 合作；声明由通讯组撰写、Tao 博客转发（Tao 本人非 AHM 成员，但在 Mastodon 上阐述了他的"Math 2.0"立场——解题不再是学科中心）。Aaronson 的 Mathocalypse 此前已报。

**判断**：撤稿是验证层在工作而非失败的证据——但注意撤回的全部**没有** Lean 形式化。经验法则：这批结果里"已 Lean 化"和"可信"高度相关，未形式化的宣称应默认打折。

## 3. GPT-6 向全部 ChatGPT 用户推送 + Intelligent UI：模型被训练成"直接输出界面"

**来源**：openai.com/index/gpt-6-for-everyone（10/7）、help.openai.com 模型文档、HN（572 分）· **已证实**

- 面向 12 亿周活的正式投放：GPT-6 在模型菜单里替换"Latest"，Instant/Medium/High/Extra High 各档由 GPT-6 Sol 驱动，Pro 档由 GPT-6 Astra 驱动（"GPT-6 Pro"）。
- **Intelligent UI**：模型不再只输出文本，而是从一套原生可流式组件库（图形、可点按钮、表单、图表）里选件组装回答，编译器让界面随生成渐进渲染。训练侧专门评了清晰度/有用性/完整性。本质是 OpenAI 版 Artifacts，但**组件选择学进了权重**，不是 harness 层拼装。
- HN 讨论点：发的是 GPT-6 Sol 而非明显更强的 6.1 Sol，有人推测 6.1 是被紧急改名顶替的 heavier model（传闻）；API 的 chat-latest 疑似已切到 GPT-6 变体。

**对你的意义**：免费用户正式吃到 GPT-6 档；"模型直接生成 UI"如果效果扎实，意味着前端脚手架类应用的护城河又薄一层。值得开一次 Chat 实测同题对比。

## 5. CrowdStrike：疑似单人攻击者用 ARTEX+Claude Code 攻破多家韩国银行——agentic 攻击的第一个公开解剖样本

**来源**：crowdstrike.com 博客（10/8）、Yonhap、iTnews · **已证实**（攻击归因为中等置信度）

- 9 月底–10 月初韩国多家金融机构（Shinhan、Hana、KB Kookmin 等）被入侵，Shinhan 泄露 25,000+ 条含收入/信用额度的记录。攻击链：中国开发的开源 agentic 渗透工具 **ARTEX** + Claude Code； CrowdStrike 称攻击者"疑似中文使用者、广东 26 岁男性、牟利动机"（中等置信度）。
- 最有价值的细节是攻击者的 OPSEC 崩塌：服务器开放目录里直接暴露了 **Claude Code 会话历史、ARTEX 配置、.claude/CLAUDE.md 和 memory 文件**——等于把完整的 AI 辅助攻击工作流拱手交出。这也是第一次能读到真实攻击者怎么用 agent harness 的公开取证材料。
- 同日 Zenity 披露 **AgentCorruption**：AWS Bedrock AgentCore 的 MicroVM 没做网络隔离，一条提示词经 SSRF 拿到 IMDS 凭证，而默认 IAM role 权限覆盖**同账号同区域所有 agent**——读他人会话、改长期记忆、掏 Secrets Manager。云厂商 agent 托管的默认权限模型首次被公开击穿的案例。

**判断**：两条合读——攻击面已经从"模型会不会作恶"变成"agent 托管基础设施的默认权限"。跑 agent 的最低自查：凭证最小化、IMDS 不可达、记忆写入要审计。

## 6. Goodfire 给 Kimi K3 / GLM-5.3 装上了生产级激活探针监控：成本降 50 倍，越狱归零

**来源**：goodfire.com/research/production-cyber-monitors-on-kimi-k3（10/8）、FAR.AI 复测 · **已证实**（FAR.AI 独立攻击验证）

- 架构：探针直接读推理栈内部激活做第一道筛（局部+全局行为表征的新探针结构），可疑的才上交 LLM judge 复核。结果：93% recall @ 5.5% FPR，Pareto 压过逐轮 judge；**<$200/百万轮次**（对照 Opus 5 逐轮判约 $200K）；不加延迟。
- 效果：Kimi K3 有害会话拦截 29%→96%，GLM-5.3 36%→91%；FAR.AI 两天 140 条已知可用越狱打下来，universal jailbreak 66→0、越狱交互 700→18。K3 上采的数据直接迁到 GLM-5.3 同样有效——**监控配方跨模型可迁移**，新模型不用重建数据管线。

**为什么重要**：解读层第一次在生产环境跑赢"大模型当保安"的成本曲线，而且是跑在国产开源权重模型上——模型不可信但激活可审计，是给"开源模型部署安全"的一条现实路线。
