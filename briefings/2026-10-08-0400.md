## 1. Claude Haiku 5.5 发布：$0.10/$0.50、1M 上下文、运行成本约为前代 1/4 —— 顺带把 Sonnet 缓存读价腰斩

**来源**：anthropic.com/claude-haiku-5-5、platform.claude.com 模型文档、Claude Code v2.1.293 changelog、Artificial Analysis · **已证实**（API 已可用，`claude-haiku-5-5`）

- 定价按 prompt 大小分两档：≤100K 输入 $0.10 输出 $0.50（覆盖旧 Haiku ~90% 请求）；>100K 输入 $0.50 输出 $2.50。缓存读 $0.01/$0.05，写 $0.125/$0.625，Batch 再 5 折。官方口径：比 Haiku 4.5（$1/$5）便宜 90%/50%，计入新 tokenizer 每个任务略多耗 token 后**实际运行成本约降 75%**。AA Intelligence Index 43。
- 规格：1M 上下文、128K 输出、adaptive thinking、默认 effort medium、速度档"最快"。定位就是高吞吐杂活（摘要/压缩/分类/检索）+ **Opus/Sonnet 的编码子智能体**。Claude Code v2.1.293 已把它设为默认 Haiku。全平台：API/Bedrock/Vertex/Foundry。
- 配套动作：**Sonnet 5.5 缓存读 $0.20→$0.10**，官方称多数 agentic 任务总成本约 -20%。
- 官方模型表顺带确认了现役梯队：Fable 5.1（$10/$50，"Slower"，adaptive 思考常开）> Opus 5.5（$4/$20）> Sonnet 5.5（$2/$10）> Haiku 5.5——Fable 是比 Opus 更高一档的旗舰，Fable 5.5 传闻仍未坐实。

**怎么做**：harness 里所有"用便宜模型干的活"（路由、triage、上下文压缩、子任务）价格锚点下移一个数量级，sub-agent 拆任务的账可以重算；之前嫌 Haiku 4.5 弱的任务值得重测（新 tokenizer + 新代际）。

## 3. openai/math 复核周：UGC、L=BPL、FFT、矩阵乘法——宣称清单比首日报道更大，验证全面落后

**来源**：scottaaronson.blog《The Mathocalypse》（HN 173 分）、postcutoff.com、quantamagazine.com、lance.fortnow.com、openai/math README · **宣称存在：已证实；宣称正确：未验证**

- 新浮出的重量级宣称（部分带 Lean）：**Khot 唯一博弈猜想（UGC）**——58 页"The Unique Games Theorem"，3SAT→固定字母表 𝔽₂^s 上 Unique Games 的确定性多项式归约，Lean scope note 明确"陈述内不含 P≠NP 假设"；若成立，Goemans-Williamson Max-Cut 和 2 倍 Vertex Cover 就是可证最优。**L=BPL/L=RL 去随机化**、超越经典的 FFT/整数乘法、Unitary Synthesis 正面解决、parity 与 QAC⁰ 分离、~4 次方随机/量子查询分离、2D 能隙哈密顿量 area law、随机近线性最大匹配、**O(n^9/4) 矩阵乘法新技术**、permanent 的 Ω(n³) 行列式下界等。P vs NP 未动。
- 复核现状：Lean 通过 ≠ 宣称成立——复杂度类命题的忠实形式化（机器、多项式时间、编码）本身就微妙，"目前没有人类真正读懂这些证明，竞赛刚开始"（Aaronson 转述其妻、做 UGC 多年的 Dana Moshkovitz 原话：手稿混乱，需要用 AI 辅助综合才能抽出 claim）。OpenAI README 新增诚实条款："部分未形式化结果可能有问题"、zeta 零点自由区和 CM 阿贝尔簇 Hodge 两件工作**不是**标准流水线产物、Re(s)>11/12 的 writeup 经人工润色。
- 数字口径注意：官方说 ~4,000 题、平均每结果 3 小时 ChatGPT Pro thinking；Aaronson 处流传的口径是 ~8,000 题、解出 ~5%。两个数字都来自 OpenAI 相关渠道，取"数千题、个位数百分比命中"为准。
- 生态反应：顾问组是 Gowers/Witten 领衔的 AGMAI——但 AGMAI 声明"咨询≠背书"；Anthropic 数学家 Alpöge 称"显然是数学史上最重要时刻"；Buckmaster 质疑尽调不足；New Scientist/Quanta/LessWrong（创造性讨论：是否有 Move 37 式的新概念）都在跟进。

**怎么做**：要真上手复核，优先看带 Comparator 配置的 Lean 工件（185 个声明可独立 lake build），TCS 方向从 Fortnow 整理的 openai/math TCS 选篇入手；别急着在报告里引用这些结果，等 whataifound/MathOverflow 的两周复核。

## 4. 对照组：Anthropic 内部模型独立发现 3SUM/APSP 算法，走"人类消化后署名"路线

**来源**：arXiv 2610.06783（10/5）、postcutoff · **已证实**（论文致谢明确记载）

- Williams（MIT）+ Alman（Columbia）：3SUM 确定性 O(n^1.9992)、APSP 有向整权 O(n^2.9995)——**首次多项式级打破教科书界**，连带推倒 Exact Triangle、Zero-Weight k-Clique 假设和三条 hinted OMV 猜想。核心是稀疏"thin matrix product"新算法（N×D、D≤N^{1/18}，只算 N²/√D 个位置用 O(N²/D^0.063) 操作）。
- 论文自述：Anthropic 员工用内部研究模型**在检查密码学构造时**意外发现该算法，模型无人工输入独立产出；Anthropic 随后用 Lean 4 + Mathlib 形式化验证了主要定理，再出钱请两位作者理解、简化、扩展、写成论文。作者对论文负全责。
- **为什么重要**：和 openai/math 形成教科书级对照——同一周内，"倾倒 722 篇未消化手稿+自己挂 Lean"vs"给人类专家署名机会+打磨后发布"。前者产出速度碾压，后者可信度碾压。scalable mind 的核心问题被具象化了：**发现能力已经过剩，瓶颈在验证与表达**。

## 5. 决策模型本周完成"标准化"：OpenAI Decisions API 公测 + Liquid 开源 d1-3B + 接口四处兼容

**来源**：OpenAI changelog/community、Vercel AI Gateway 文档、liquid.ai、OpenRouter、llama.cpp v0.6.0 · **已证实**

- **OpenAI Decisions API 公测**（10/6）：`POST /v1/decisions`，跑 gpt-6-luna 变体，对同一份输入一次返回 predicate/choice/score 三类带概率的 typed answer，**不生成文本**（output_tokens=0）。官方称决策速度比走 Responses API 的 GPT-6 Luna 快 10×；第三方评测记录基础价 ~$0.10/M 输入。支持逐题 refusal、confidence 与 option probability 分离。
- **生态同周对齐**：Vercel AI Gateway 上线 OpenAI 兼容 `/v1/decisions`（换 base URL 即可，可路由到 Jev/d1/Laya/Clef 等任何决策模型）；OpenRouter 新增 `gpt-6-luna-decisions`、Clef（27B，$0.24/M）与 Clef Flash（9B，$0.09/M）；llama.cpp v0.6.0 自带 `/v1/systemone` 决策端点。
- **Liquid 开源 d1-3B + d1-omni-600M**：d1-3B 基于 LFM2.5-VL-3B，Decision Index 48.57——**10B 以下第一，打平 12 倍大的 Decider 35B-A3B**；4090 上 8ms、Jetson Orin Nano 50ms。d1-omni-600M 为文本+图或文本+音的双模态实验版（DI 15.95）。
- **意义**：routing/triage/guardrail/judge 这层从"拿生成模型凑合"正式变成独立 API 形态——零输出 token、一次前向、返回校准概率。一周五家对齐接口（OpenAI/Vercel/OpenRouter/Cloudflare/llama.cpp），标准收敛速度罕见。

## 6. Agent Lightning v1.0（MSRA）：部署态 harness 直接进 RL，3.5K 行代码的"harnessed agentic RL"

**来源**：microsoft.github.io/agent-lightning、arXiv 2608.17528 · **已证实**（框架+论文+可复现 pipeline 均开源）

- 范式：训练引擎不再自己跑环境循环——**部署时的 agent harness（Claude Code 式）原样接管交互**，训练侧只通过 LLM 端点代理观察 request/response 对。verl Uni-Agent、AReaL 2.0、slime、Polar 已跟进此路线，本文第一次把该范式的难点系统讲清：retokenization、样本合并、advantage 计算、loss 归一化、backend 调度——处理不好就训不稳。
- 结果：仅 6K 样本、中等算力，Qwen3.5-9B 在 SWE-bench Verified 41.8%→56.4%（+14.6），coding-agent RL 全流程可复现，原生 K8s Job 跑 agent。
- **意义**：训练-部署 harness 不一致是 agent RL 一直咽不下的误差源；v1.0 用极小代码量给了参考实现，"你跑的那个 harness 直接吃 RL"从口号变成可复现基线。

## 7. Nemotron 双金：IOI 2026 535.4 分（压过人类第一）+ IMO 30/42，配方全开

**来源**：huggingface.co/blog/nvidia（10/7）、arXiv 2609.10712 · **已证实**（IMO 由官方阅卷人评分；IOI 为同约束前瞻性实测，非官方排名）

- IOI：Nemotron-3-Ultra-CC（550B/55B 激活，仅 SFT）+ GenCorrect 反馈式推理，实赛同约束跑出 **535.4/600，超金牌线 361 和人类最高分 498**。姊妹版 Nano-CC（30B/3B）走 SFT+RL。
- IMO：三个 Nemotron 3 Ultra checkpoint（GA+两个 post-train 专家版）组 generate-verify-refine 纯自然语言流水线，**无形式化、无工具、无网络**，30/42 达金线 29。开源两个专家 checkpoint、训练数据、训推代码、提交解答、以及 200 题新基准 Nemotron-IMO-Bench。
- **注意**：IOI 535>498 的"超人类"是模型+test-time 流水线对同题同约束的分数，IOI 官方不认；但开源程度（数据+代码+bench）是真金白银，竞赛题方向的可复现上限被公开抬了一档。
